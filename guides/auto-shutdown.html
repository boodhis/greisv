Автоматическое выключение сервера

Если сервер работает только для медиа и не нужен ночью, можно настроить автоматическое выключение. Это экономит электричество и продлевает жизнь железу.

Вариант 1: Разовое выключение

Когда сел смотреть фильм и знаешь, через сколько часов пойдёшь спать:

# Выключить через 2 часа (120 минут)
sudo shutdown -h +120

# Выключить ровно в 23:30
sudo shutdown -h 23:30

Разбор команды

  • shutdown — команда выключения/перезагрузки
  • -h — выключение (halt)
  • +120 — через 120 минут
  • 23:30 — в точное время

Отмена таймера

Если передумал и хочешь продолжить работу:

sudo shutdown -c

Разбор команды

-c — отмена запланированного выключения. Система напишет Shutdown cancelled.

Вариант 2: Постоянное расписание

Чтобы сервер автоматически выключался каждую ночь (например, в 01:30):

sudo crontab -e

Добавь в конец файла:

30 1 * * * /sbin/poweroff

Разбор команды

  • 30 — минуты (30 минут)
  • 1 — часы (1 час ночи)
  • * — каждый день, каждый месяц, каждый день недели
  • /sbin/poweroff — путь к команде безопасного выключения

Сохрани файл (Ctrl+O, Enter, Ctrl+X) и сервер будет выключаться каждую ночь в 01:30.

Проверка расписания

# Посмотреть текущее расписание
sudo crontab -l

# Удалить расписание
sudo crontab -r

Разбор команды

  • -l — показать текущий crontab
  • -r — удалить весь crontab

Автоматическое включение

Сервер можно настроить на автоматическое включение при подаче питания:

  1. Зайди в BIOS (Del или F2 при загрузке)
  2. Найди раздел Power Management
  3. Включи опцию Restore on AC Power Loss (или аналогичную)
  4. Сохрани и выйди

Теперь при включении питания (после отключения электричества) сервер автоматически запустится.

Готово!

Теперь ты можешь: - ✅ Выключать сервер по таймеру - ✅ Настраивать постоянное расписание - ✅ Автоматически включать сервер при подаче питания

Автоматическое выключение — простой способ экономить электричество и продлевать жизнь железу.
