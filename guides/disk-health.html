Мониторинг здоровья дисков

S.M.A.R.T. (Self-Monitoring, Analysis and Reporting Technology) — система самодиагностики дисков. Помогает предсказать выход диска из строя.

Установка smartmontools

sudo apt update && sudo apt install -y smartmontools

Разбор команды

Устанавливает пакет smartmontools — утилиты для мониторинга дисков через S.M.A.R.T.

Проверка дисков

Список всех дисков

lsblk

Разбор команды

Показывает все блочные устройства (диски, разделы, флешки).

Проверка SMART-статуса

# Для внутренних дисков
sudo smartctl -H /dev/sda

# Для USB-дисков
sudo smartctl -d sat -H /dev/sdb

Разбор команды

  • smartctl — утилита для мониторинга дисков
  • -H — показать общий статус (PASSED/FAILED)
  • -d sat — для USB-дисков через SAT-мост

Подробный анализ

# Все атрибуты SMART
sudo smartctl -a /dev/sda

# Только критические атрибуты
sudo smartctl -A /dev/sda | grep -E "Reallocated|Pending|CRC"

На что смотреть?

АтрибутНазваниеОпасность
5Reallocated_Sector_Ct> 0 — диск "сыпется"
197Current_Pending_Sector> 0 — проблемы с чтением
199UDMA_CRC_Error_CountРастёт — проблема с кабелем

Запуск тестов

# Короткий тест (~2 минуты)
sudo smartctl -t short /dev/sda

# Длинный тест (несколько часов)
sudo smartctl -t long /dev/sda

# Просмотр результатов теста
sudo smartctl -l selftest /dev/sda

Разбор команды

  • -t short — запустить короткий тест
  • -t long — запустить длинный тест
  • -l selftest — показать результаты тестов

Мониторинг нагрузки

# Просмотр нагрузки в реальном времени
sudo iotop -o

Разбор команды

Показывает, какие процессы больше всего нагружают диск.

Автоматический мониторинг

Настрой smartd для автоматической проверки:

sudo nano /etc/smartd.conf

Добавь:

/dev/sda -a -o on -S on -s (S/../.././02|L/../../6/03) -m root

Перезапусти:

sudo systemctl restart smartd

Усыпление и размонтирование дисков

Для USB-дисков, которые нужны не постоянно: усыпление (hdparm -y) экономит ресурс и шум. Команды проверены на стеке внешних дисков:

# проверить, спит ли диск (вместо sdb — имя устройства)
sudo hdparm -C /dev/sdb        # active/idle или standby

# усыпить (размонтировать + перевести в standby)
sudo umount /dev/sdb1 2>/dev/null; sudo hdparm -y /dev/sdb

# полное отключение питания USB-диска
sudo udisksctl power-off -b /dev/sdb

# размонтировать (не усыпляя)
sudo umount /mnt/storage
sudo umount -l /mnt/storage    # ленивое, если диск занят
sudo fuser -km /mnt/storage    # убить процессы, держащие точку монтирования

# смонтировать обратно
sudo mount /dev/sdb1 /mnt/storage

Разбор

  • hdparm -C — статус: active, idle или standby
  • hdparm -y — перевести головки в standby (проснётся сам при обращении)
  • umount -l — отложенное размонтирование, если «target is busy»
  • udisksctl power-off — полностью выключить питание USB-диска
