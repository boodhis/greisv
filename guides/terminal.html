Терминал: Полезные команды

Терминал — это основной инструмент в Linux. Вот полезные команды.

Навигация

# Текущая директория
pwd

# Список файлов
ls
ls -la  # с скрытыми файлами и деталями

# Переход в директорию
cd /path/to/directory

# Переход в домашнюю директорию
cd ~

Разбор команды

  • pwd — print working directory (текущая директория)
  • ls -la — список файлов с деталями и скрытыми файлами
  • cd — change directory (смена директории)

Работа с файлами

# Копирование
cp file1.txt file2.txt
cp -r dir1/ dir2/  # рекурсивно (папки)

# Перемещение/переименование
mv old.txt new.txt
mv file.txt /new/path/

# Удаление
rm file.txt
rm -rf directory/  # рекурсивно с подтверждением

Осторожно!

Команда rm -rf удаляет файлы безвозвратно. Убедись, что ты знаешь, что удаляешь!

Поиск

# Поиск файла
find /path -name "filename"

# Поиск по содержимому
grep "text" file.txt
grep -r "text" /path/  # рекурсивно

# Поиск команды
which command
whereis command

Разбор команды

  • find — поиск файлов по имени и атрибутам
  • grep — поиск по содержимому файлов
  • which — показать путь к команде

Просмотр файлов

# Просмотр содержимого
cat file.txt

# Построчный просмотр
less file.txt
more file.txt

# Первые/последние строки
head file.txt
tail file.txt
tail -f file.txt  # режим реального времени

Разбор команды

  • cat — показать всё содержимое файла
  • less — построчный просмотр (q для выхода)
  • tail -f — следить за обновлениями файла в реальном времени

Права доступа

# Изменение прав
chmod 755 file.sh
chmod +x script.sh  # сделать исполняемым

# Смена владельца
chown user:group file.txt

Разбор команды

  • chmod — change mode (изменение прав доступа)
  • 755 — owner: rwx, group: rx, others: rx
  • chown — change owner (смена владельца)

Работа с процессами

# Список процессов
ps aux
top
htop

# Убить процесс
kill PID
kill -9 PID  # принудительно

# Поиск процесса
pgrep "name"

Разбор команды

  • ps aux — показать все процессы
  • kill -9 — принудительное завершение
  • pgrep — найти PID по имени процесса

Сетевые команды

# Проверка подключения
ping google.com

# Сканирование портов
nmap localhost

# Трассировка
traceroute google.com

Разбор команды

  • ping — проверка доступности хоста
  • nmap — сканирование открытых портов
  • traceroute — маршрут пакетов

Сокращения

# Последняя команда
!!

# Подстановка последнего аргумента
mkdir dir
cd !$

# История команд
history
!123  # выполнить команду 123 из истории

Терминал — это мощный инструмент. Чем больше практикуешься, тем быстрее работаешь.
