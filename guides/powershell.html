Windows для Linux-админа: PowerShell

Ты привык к Bash, а тут 1С, RDP и диск 600 МБ, который не удаляется. Главное отличие: в Linux всё — текст (grep/awk), в PowerShell всё — объект.

Маст-хэв (повседневное)

ЗадачаКоманда (аналог Linux)
IP, MAC, шлюзipconfig /all · Get-NetIPAddress -AddressFamily IPv4
Проверить порт/сайтtnc google.com · tnc <host> -Port 22 (замена ping/telnet)
Топ-10 процессов по CPUGet-Process | Sort-Object CPU -Descending | Select-Object -First 10 (top)
Починить системуsfc /scannow
Поставить софтwinget install telegram (apt)
Логи в реальном времениGet-Content log.txt -Wait -Tail 20 (tail -f)
Фильтр объектовGet-Service | Where-Object {$_.Status -eq "Stopped"} (grep)
Поиск файловGet-ChildItem -Recurse -Filter "*.log" (find)
JSON-вывод для скриптовGet-Service | ConvertTo-Json
Открытое свойство без мусора(Get-Service -Name "bits").Status
Модель объектов

Когда ты пишешь Get-Service, получаешь не строку, а объект: ставь точку и обращайся к любому свойству. Where-Object + Select-Object ≈ твои grep + awk.

pktmon правильно (не всё подряд)

pktmon filter add -p 443                          # ловить только HTTPS
pktmon start --etw -m real-time                   # в реальном времени
Ctrl+C                                            # остановить
pktmon filter remove                              # очистить фильтры

Почему list не сработало? PowerShell использует связку «Глагол-Существительное» (Get-Service), а pktmon — внешняя exe, свои подкоманды принимает одной строкой: pktmon list.

Управление адаптерами и дисками

  • Перезапуск адаптера (аналог «выдернуть кабель»): Disable-NetAdapter -Index 66 → Enable-NetAdapter -Index 66.
  • Скорость соединения: Get-NetAdapter | Select-Object Name, LinkSpeed.
  • Сброс всей сети (перезагрузка!): netcfg -d — удалит все виртуальные свитчи и настройки адаптеров.
  • IP конкретных адаптеров: Get-NetIPAddress -InterfaceIndex 11, 66.
  • Температура дисков: 
    Get-PhysicalDisk | ForEach-Object {
    $stats = $_ | Get-StorageReliabilityCounter
    [PSCustomObject]@{ Model = $_.FriendlyName; Temp = "$($stats.Temperature)°C" }
} | Format-Table -AutoSize
  • Состав дисков: Get-PhysicalDisk | Select-Object FriendlyName, BusType, MediaType.
  • Удалить защищённый системный раздел (600 МБ): diskpart → list disk → select disk 1 → list partition → select partition 1 → delete partition override (параметр override — для защищённых системных разделов).
Виртуальный адаптер vEthernet

Наличие vEthernet (Default Switch) — признак включённого Hyper-V или WSL2. Для Linux-админа отличный ход — поставить WSL2: твой привычный терминал прямо внутри Windows.
