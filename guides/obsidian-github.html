Синхронизация Obsidian через GitHub

Бесплатная синхронизация заметок между Linux, macOS и Windows — без флешек и сторонних облаков.

Шаг 1. SSH-ключ (Linux/macOS)

Чтобы GitHub пускал компьютер без пароля, создаётся SSH-ключ:

# создать ключ
ssh-keygen -t ed25519 -C "you@example.com"

# добавить ключ в систему
eval "$(ssh-agent -s)" && ssh-add ~/.ssh/id_ed25519

# скопировать ключ для GitHub
cat ~/.ssh/id_ed25519.pub

Скопированный текст вставь на GitHub: Settings → SSH and GPG keys → New SSH key.

Проверь связь:

ssh -T git@github.com

Шаг 2. Первый запуск

Если папка с заметками уже есть, привяжи её к репозиторию:

cd "/путь/к/папке/Obsidian"
git init

# игнорируем мусорные файлы Obsidian
echo ".obsidian/workspace.json
.obsidian/workspace-mobile.json
.obsidian/cache/
.obsidian/graph.json" > .gitignore

git add .
git commit -m "initial sync"
git branch -M main
git remote add origin git@github.com:username/repo.git
git push -u origin main

Дальше

На остальных машинах клонируешь репозиторий один раз, а затем — обычный git pull / git push. Добавь ключи каждой машины на GitHub, и все они получат доступ.

Приём

Храни .gitignore на месте: workspace.json и кэш графа — личное состояние интерфейса, конфликуют и не нужны в репозитории.

Основы Obsidian и Markdown

Сила Obsidian — не в кнопках, а в связях заметок. Ты связываешь мысли, и получается личная база знаний или «второй мозг».

Ссылка на заметку[[Название заметки]]
  • Создание ссылок: введи [[ — Obsidian предложит существующие заметки; если такой нет, она создастся при клике по ссылке.
  • Обратные ссылки (Backlinks): в правой панели видно все заметки, которые ссылаются на текущую — контекст и связанные идеи.
  • Граф заметок (Graph View): иконка графа слева — визуальная карта всех заметок и связей.

Совет

Ctrl + Shift + V вставляет текст без переформатирования; код между тройными квотами ``` подсвечивается автоматически.
