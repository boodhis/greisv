Как сайт обновляется из Obsidian

Идея
> Пишешь обычную заметку в Obsidian — через пару минут она уже на сайте. Никаких > правок HTML вручную. ## Как это устроено Волт Obsidian — единственный источник текста. В нём есть зеркальная папка **«Сайт»**: каждая подпапка = раздел сайта, каждый `.md`-файл = страница. Скрипт `gen/gen_vault.py` на хомлабе: 1. после синка волта проверяет, менялась ли папка «Сайт»; 2. конвертирует Markdown → HTML (таблицы, код, callout-блоки, вики-ссылки); 3. кладёт страницу в нужный раздел `~/greisv` и согласует `sitemap.xml` и офлайн-кеш `sw.js`; 4. прогоняет тесты и пушит в репозиторий. Дальше GitHub Actions деплоит сайт на Pages. Весь конвейер — открытый код и без платных сервисов. ## Правила публикации - Подпапки-разделы: `getting-started / services / guides / homelab / resources / hobbies`. - `README.md` и файлы `_*` не публикуются. - Шапка заметки (`frontmatter`): `title`, `description`, `priority`. - Обычный Markdown + Obsidian-фишки: | Синтаксис | Что получится | |---|---| | `другая страница` | ссылка на страницу сайта | | `> [!note] Заголовок` | callout-блок | | `| таблицы | md |` | HTML-таблица | ## Что осталось вручную Интерактивные части (тренажёр карточек, PWA, генераторы «Электрики», манифест) — как раньше: правятся в репозитории `greisv`. Через волт идёт контент статей.
