Веб-разработка — шпаргалка

Стартовый набор для своей первой веб-страницы на Ubuntu: версии Node, «живой» сервер, каркас HTML.

Node.js (nvm)

nvm ls               # какие версии установлены
nvm install --lts    # поставить самую свежую стабильную
node -v              # проверить версию Node.js
npm -v               # проверить менеджер пакетов

Управление проектом

mkdir -p ~/projects/my-site   # новая папка для сайта
cd ~/projects/my-site         # войти
code .                        # открыть в VS Code

Запуск серверов (в терминале VS Code)

npx serve        # простой статический сервер
# «живой» сервер — автообновление при сохранении файла:
npx browser-sync start --server --files "*.html, *.css"
ctrl+c           # остановить сервер

Базовая страница

<!DOCTYPE html>
<html>
<head>
    <title>Test Page</title>
</head>
<body>
    <h1>Сервер на Acer работает!</h1>
    <script>console.log("JS в деле");</script>
</body>
</html>

Полезное на Ubuntu

  • inxi -Fx — полная инфа о железе (то, с чего начинали в inxi).
  • sudo snap install <название> — установка софта (так ставили Obsidian).
  • python3 -m venv venv — виртуальное окружение Python (чтобы не мусорить в системе).
Приём в терминале

Ctrl + Shift + V в Obsidian — вставить без переформатирования; код в тройных квотах ``` — автоматически подсветится.
