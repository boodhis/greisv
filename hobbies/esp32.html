🔩 ESP32 / ESPHome

Маленькие платы за пару сотен рублей, которые делают дом умным. ESPHome — это YAML-конфиги вместо C++.

Наша панель Heltec V3

Это та самая умная панель, у которой интервальное повторение слов: экран, Wi-Fi-модуль, кнопки. Она по счёту и хранит прогресс (интервалы 2·5·10·25·60…11520 мин), а её словарь — источник колод «Слова» и «Команды» в тренажёре.

Easiest start: ESPHome

  • Установил esphome (pip) или контейнер на сервере.
  • Написал YAML: esp32 → api / wifi / sensor / switch.
  • Зашил по Wi-Fi: esphome run my.yaml.
esphome:
  name: kitchen-sensor
esp32:
  board: esp32dev
  framework:
    type: arduino
wifi:
  ssid: "Home"
  password: "secret"
sensor:
  - platform: dht
    pin: GPIO4
    temperature:
      name: "Kitchen temperature"
    humidity:
      name: "Kitchen humidity"

Связки

  • MQTT — умный дом на шине «издатель/подписчик». Раздел MQTT / ESPHome.
  • Электрика — только когда освоил безопасность.
  • Homelab — брокер и автоматика крутятся на сервере homelab.
