Зачем это всё?

Цифровая Крепость — это проект для тех, кто хочет:

  • 🐧 Перейти на Linux но боится что "всё сломается"
  • 🏠 Собрать homelab — домашнюю лабораторию для обучения и экспериментов
  • 🔧 Научиться настраивать серверы через реальные примеры
  • 📚 Найти ответы на частые вопросы по Linux

Концепция

Это не просто набор команд. Это путеводитель по реальному homelab-проекту:

  • Живой сервер: Ubuntu Server 24.04 на старом ноутбуке Acer
  • Реальные сервисы: Docker, Samba, Navidrome, Immich, ESPHome
  • Практический опыт: все примеры проверены на практике
  • Открытый код: всё можно скопировать и адаптировать
