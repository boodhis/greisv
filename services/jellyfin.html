Jellyfin: обложки и метаданные

Почему не подгружаются постеры и как обойти DNS-блокировку TMDB.

Симптом

В Jellyfin не подгружаются обложки и метаданные. В логе ошибка:

System.Net.Http.HttpRequestException: Connection refused (api.themoviedb.org:443)
at TMDbLib.Client.TMDbClient.GetConfigAsync()

Причина

api.themoviedb.org резолвится в 127.0.0.1 — это DNS-блокировка TMDB на роутере, а не блокировка на уровне сети.

Как различать

ПроверкаРезультатВывод
dig api.themoviedb.org127.0.0.1DNS-блокировка
dig api.themoviedb.org @1.1.1.1 +tcpреальный IP (18.165.x.x)глобально DNS не отравлен
curl --resolve api.themoviedb.org:443:<ip> ...HTTP 401сеть пропускает

Решение: правим /etc/hosts

Если сеть не блокирует IP — VPN не нужен, достаточно прописать реальные IP TMDB в /etc/hosts. IP берём через Cloudflare:

dig +short +tcp <домен> @1.1.1.1

Пример после правки (бекап /etc/hosts.bak):

18.165.122.27  api.themoviedb.org
18.165.140.123 www.themoviedb.org
138.199.36.8   image.tmdb.org
52.85.154.25   tmdb.org
143.204.238.64 themoviedb.org

Затем:

sudo systemctl restart jellyfin
sudo resolvectl flush-caches

и рефреш библиотек (или через API):

POST /Items/{libraryId}/Refresh?metadataRefreshMode=Default

Внимание

IP CloudFront — anycast, динамические, могут смениться. Если перестанет работать — заново вытяни через dig @1.1.1.1.

Рефреш библиотек через API

# авторизация
POST /Users/AuthenticateByName  {"Username":"...","Pw":"..."}  + X-Emby-Authorization

# полный список библиотек
GET  /Library/VirtualFolders

# рефреш библиотеки (рекурсивно подтянет метаданные)
POST /Items/{libraryId}/Refresh?metadataRefreshMode=Default

Организация контента без переноса данных

Если фильмы и сериалы вперемешку в одной папке, а переносить данные некуда — подключай их в библиотеки симлинками:

sudo ln -sfn "/mnt/700/down/Supernatural.2005-2020.hdrip_[teko]" "/mnt/storage/serials/Supernatural"

Нюанс

Папки-коллекции (Бонд, Рэмбо, Гарри Поттер и т.п.) Jellyfin может показать как одну запись с частями, а не отдельные фильмы. Если нужно разбить — отдельная настройка contentType.

Проверено на реальном сервере (Jellyfin 10.11 из официального apt-репозитория).
