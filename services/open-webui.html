Open WebUI: веб-морда для Ollama

Локальный веб-чат с LLM: тяжёлые модели крутит мощный ПК, открываешь с любого устройства в сети.

Идея

Ollama запускает модели локально, но у него нет удобного веб-интерфейса. Open WebUI — это красивая веб-морда (чат, история, RAG), которую крутит контейнер. Схема:

  • Мощный стационар — Ollama слушает сеть (0.0.0.0:11434).
  • Homelab-сервер — контейнер Open WebUI, смотрит на стационар.
  • YouTube и MacBook — открывают веб-морду по адресу лабы.

Шаг 1. Ollama слушает сеть

Совет

Привяжи IP стационара в роутере по MAC-адресу (например 192.168.0.100), чтобы он не менялся.

Если стационар на Linux

sudo systemctl edit ollama.service

Вставь между строками:

[Service]
Environment="OLLAMA_HOST=0.0.0.0"

Сохрани (Ctrl+O, Enter, Ctrl+X) и перезапусти:

sudo systemctl daemon-reload
sudo systemctl restart ollama

Если стационар на Windows

  1. Win + R → sysdm.cpl → вкладка «Дополнительно» → «Переменные среды…».
  2. В пользовательских переменных создай: имя OLLAMA_HOST, значение 0.0.0.0.
  3. Полностью закрой Ollama через трей и запусти заново.

Шаг 2. Контейнер Open WebUI на сервере

Замени 192.168.0.100 на реальный IP твоего стационара:

docker run -d \
  -p 8080:8080 \
  -e OLLAMA_BASE_URL="http://192.168.0.100:11434" \
  -v open-webui:/app/backend/data \
  --name open-webui \
  --restart always \
  ghcr.io/open-webui/open-webui:main

Что делает команда

ФлагЗачем
-dфоновый режим (как демон)
-p 8080:8080веб-морда доступна на 8080 порту сервера
-e OLLAMA_BASE_URLадрес твоего «вычислительного центра» — ключевая переменная
-v open-webui:…постоянный том: аккаунты, чаты и база RAG не пропадут
--restart alwaysконтейнер сам поднимется после перезагрузки сервера

Шаг 3. Диванный запуск

  1. Открой браузер и перейди на http://192.168.0.244:8080.
  2. Зарегистрируй первого пользователя — это локальный админ, данные останутся на твоём сервере.
  3. В левом верхнем углу — выбор модели: там уже видны все модели, скачанные на стационаре.

Какие модели брать

Ориентир — видеопамять (VRAM) GPU. Для 12 ГБ (RTX 3060) рабочая тройка:

МодельЗачем
qwen2.5:7b / qwen3:14bкод и русский язык
llama3.1:8bэталон логики и общения
mistral-nemo (12B)потолок точности для 12 ГБ
nomic-embed-textэмбеддинги для RAG

Проверить, какие модели уже скачаны, и ставить их Ollama:

ollama list      # список моделей
curl http://localhost:11434/api/tags

Подсказка: у крупных моделей держи num_ctx 8–16k, иначе KV-кэш уедет в CPU и скорость упадёт в разы.

Python-скрипт к модели

Python служит «клеем» между нейронкой и твоими задачами. Базовый запрос к Ollama по API:

import requests

def ask_ai(prompt):
    url = "http://localhost:11434/api/generate"
    data = {"model": "qwen2.5:7b", "prompt": prompt, "stream": False}
    response = requests.post(url, json=data)
    return response.json()['response']

print(ask_ai("Зачем нужен Python?"))

Полезные библиотеки: requests — запросы к API, os/shutil — файлы и папки, pandas — таблицы и большие данные. Алиасы в ~/.bashrc: alias ai='ollama run qwen2.5:7b', alias gpu='watch -n 1 nvidia-smi'.

Управление контейнером

docker stop open-webui
docker start open-webui

Бесплатно, локально, без облаков: чат-бот живёт в твоей сети — даже без интернета.
