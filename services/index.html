Как установить?

Все сервисы запускаются через Docker. Пример:

# Клонируем docker-compose файл
git clone https://github.com/boodhis/homelab-infra.git

# Запускаем сервис
cd homelab-infra/services/navidrome
docker compose up -d

Разбор команды

  • docker compose up -d — запустить контейнеры в фоновом режиме
  • -d — detached (отсоединённый от терминала)

Мониторинг

Все сервисы можно мониторить через:

  • Systemd: systemctl status <сервис>
  • Docker: docker ps, docker logs <контейнер>
  • Нетдашборд: http://192.168.0.244 (наш дашборд)

Каждый сервис подробно описан в отдельном разделе.
