🕸 MQTT / Mosquitto

MQTT — лёгкий протокол «издатель / подписчик» для умного дома. Брокер — Mosquitto, самый распространённый открытый. Это шина, через которую датчики отдают данные, а скрипты и HA их забирают.

Ключевые понятия

ТерминЧто это
ТопикАдрес сообщения; иерархия через /. Пример: heltec/node1/sensor
PayloadСодержимое: текст, JSON, бинарь
QoS0 — «выстрелил и забыл», 1 — «хотя бы раз», 2 — «ровно раз»
RetainБрокер запоминает последнее сообщение топика и отдаёт его новым подписчикам
Will«Завещание» — публикуется, если клиент отключился нештатно

Mosquitto в Docker

Compose-файл:

version: "3.8"
services:
  mosquitto:
    image: eclipse-mosquitto:2.0
    volumes:
      - /opt/mosquitto/config:/mosquitto/config:ro
      - /opt/mosquitto/data:/mosquitto/data
      - /opt/mosquitto/log:/mosquitto/log
    ports:
      - "1883:1883"   # MQTT plaintext
      - "8883:8883"   # MQTT over TLS
      - "9001:9001"   # WebSocket
    restart: unless-stopped

/opt/mosquitto/config/mosquitto.conf:

listener 1883
allow_anonymous false
password_file /mosquitto/config/passwd

persistence true
persistence_location /mosquitto/data/

log_dest file /mosquitto/log/mosquitto.log
log_type error
log_type warning
log_type notice
log_type information

Пароль для клиента

docker run --rm -it -v /opt/mosquitto/config:/mosquitto/config \
  eclipse-mosquitto:2.0 mosquitto_passwd -c /mosquitto/config/passwd iot-client

Публикация и подписка

Аналог «проверки труб»:

# Подписка на топик (в одном терминале)
mosquitto_sub -h localhost -t "test/topic"

# Отправка сообщения (в другом)
mosquitto_pub -h localhost -t "test/topic" -m "Hello!"

Слушать всё

# Все сообщения, с топиком
mosquitto_sub -h localhost -t "#" -v

# Статус клиентов брокера
mosquitto_sub -h localhost -t "$SYS/broker/clients/connected"

Форматы вывода -F

Подстановки: %t топик, %p payload, %j JSON pretty, %I ISO-время, %U unix, @H:%M:%S — время.

mosquitto_sub -h localhost -t "heltec/#" -F "@H:%M:%S %t: %p"
mosquitto_sub -h localhost -t "heltec/#" -F "%j"

СимптомПричинаРешение
