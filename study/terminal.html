Терминал: Полезные команды

Терминал — это основной инструмент в Linux. Вот полезные команды.

Навигация

# Текущая директория
pwd

# Список файлов
ls
ls -la  # с скрытыми файлами и деталями

# Переход в директорию
cd /path/to/directory

# Переход в домашнюю директорию
cd ~

Разбор команды

  • pwd — print working directory (текущая директория)
  • ls -la — список файлов с деталями и скрытыми файлами
  • cd — change directory (смена директории)

Работа с файлами

# Копирование
cp file1.txt file2.txt
cp -r dir1/ dir2/  # рекурсивно (папки)

# Перемещение/переименование
mv old.txt new.txt
mv file.txt /new/path/

# Удаление
rm file.txt
rm -rf directory/  # рекурсивно с подтверждением

Осторожно!

Команда rm -rf удаляет файлы безвозвратно. Убедись, что ты знаешь, что удаляешь!

Поиск

# Поиск файла
find /path -name "filename"

# Поиск по содержимому
grep "text" file.txt
grep -r "text" /path/  # рекурсивно

# Поиск команды
which command
whereis command

Разбор команды

  • find — поиск файлов по имени и атрибутам
  • grep — поиск по содержимому файлов
  • which — показать путь к команде

Просмотр файлов

# Просмотр содержимого
cat file.txt

# Построчный просмотр
less file.txt
more file.txt

# Первые/последние строки
head file.txt
tail file.txt
tail -f file.txt  # режим реального времени

Разбор команды

  • cat — показать всё содержимое файла
  • less — построчный просмотр (q для выхода)
  • tail -f — следить за обновлениями файла в реальном времени

Права доступа

# Изменение прав
chmod 755 file.sh
chmod +x script.sh  # сделать исполняемым

# Смена владельца
chown user:group file.txt

Разбор команды

  • chmod — change mode (изменение прав доступа)
  • 755 — owner: rwx, group: rx, others: rx
  • chown — change owner (смена владельца)

Работа с процессами

# Список процессов
ps aux
top
htop

# Убить процесс
kill PID
kill -9 PID  # принудительно

# Поиск процесса
pgrep "name"

Разбор команды

  • ps aux — показать все процессы
  • kill -9 — принудительное завершение
  • pgrep — найти PID по имени процесса

Сетевые команды

# Проверка подключения
ping google.com

# Сканирование портов
nmap localhost

# Трассировка
traceroute google.com

Разбор команды

  • ping — проверка доступности хоста
  • nmap — сканирование открытых портов
  • traceroute — маршрут пакетов

Сокращения

# Последняя команда
!!

# Подстановка последнего аргумента
mkdir dir
cd !$

# История команд
history
!123  # выполнить команду 123 из истории

Скорость ядер процессора

Посмотреть реальную частоту по всем ядрам в реальном времени:

watch -n 1 "grep 'cpu MHz' /proc/cpuinfo"

Перевести процессор в режим performance (максимальная частота вместо экономии):

sudo apt install cpupower-gui    # графический интерфейс
sudo cpupower frequency-set -g performance   # или просто команда

# на постоянной основе:
sudo apt install cpufrequtils
echo 'GOVERNOR="performance"' | sudo tee /etc/default/cpufrequtils
sudo systemctl restart cpufrequtils

Тренажёры слепой печати (чтобы быстрее админить)

Админишь в терминале — моторные навыки клавиатуры окупаются сразу. Три уровня:

  • GNU Typist (sudo apt install gtypist) — системный учебник: серия уроков латиницы QWERTY, не пустит дальше без минимального процента ошибок. Запуск: просто gtypist, урок Q1.
  • ttyper — набить скорость на словах: поток случайных английских слов, ошибки подсвечиваются, в конце WPM. Без установки: docker run -it --rm maxwellstein/ttyper.
  • vimtutor — если пользуешься Vim: интерактивный учебник, одновременно учишься и печатать, и управлять текстом (команды h j k l…).

Терминал в стиле «кинохакера»

Всё работает внутри tmux:

  • btop (sudo apt install btop → btop) — красивый монитор ресурсов: графики, температура, стильный интерфейс. Альтернатива — gtop (nodejs, выглядит футуристично).
  • hollywood (sudo apt install hollywood → hollywood) — консоль «кинохакера»: сам разбивает экран на окна, карты, коды, логи.
  • genact (sudo apt install genact → genact) — симулятор бессмысленной активности (компиляция ядра, скан сети). Выглядит серьёзно, на деле — заставка.
  • mc — Midnight Commander, двухпанельный файловый менеджер (не печатать длинные пути).
  • fastfetch / neofetch — логотип дистрибутива и краткая инфа о железе.
  • yt-dlp + mpv — YouTube прямо в терминале в ASCII-графике: mpv --vo=tct https://www.youtube.com.
  • mapscii — карта мира в терминале: telnet mapscii.me.
  • Погода и фазы Луны: curl wttr.in/Moscow и curl wttr.in/Moon.

Заставка «Матрица», когда терминал простаивает — настройка tmux (300 = секунд, потом cmatrix):

tmux set-option lock-after-time 300 && tmux set-option lock-command "cmatrix -s -B"

Чтобы работало всегда (после перезагрузки) — добавь в ~/.tmux.conf:

set -g lock-after-time 300
set -g lock-command "cmatrix -s -B"
