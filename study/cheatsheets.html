Git

КомандаЧто делает
git statusчто изменено
git add -A && git commit -m "…"закоммитить всё
git push / pullотправить / получить
git log --oneline -10история кратко
git diffчто именно поменялось
git reset --hard HEAD~1откатить последний коммит

systemd

КомандаЧто делает
systemctl status юнитсостояние и последний лог
systemctl enable --now юнитвключить и запустить сразу
journalctl -u юнит -eхвост журнала юнита
journalctl -fследить за логом вживую

Docker

КомандаЧто делает
docker psзапущенные контейнеры

docker system pruneпочистить хлам
