Обучение

Работа с файлами в Python: open/with, режимы, pathlib, JSON и пример записи отчёта.

Почти любой скрипт рано или поздно читает или пишет файл: конфиг, лог, отчёт. Здесь — open, with, режимы, pathlib и JSON, плюс пример «записать отчёт».

open и with

with open("notes.txt", "r", encoding="utf-8") as f:
    text = f.read()

with закрывает файл даже при ошибке. Всегда указывай encoding="utf-8" — иначе на чужой машине получишь кракозябры.

Режимы

РежимЧто делает
rчтение, файл должен существовать
wзапись, старый файл стирается
aдозапись в конец
xсоздать, упадёт если файл есть
rb / wbбинарный режим

Чтение по строкам

with open("access.log", "r", encoding="utf-8") as f:
    for line in f:
        if " 500 " in line:
            print(line.rstrip())

Для больших файлов не читай целиком — итерация по строкам не грузит память.

pathlib

Современный способ работы с путями. Кроссплатформенно и читаемо.

from pathlib import Path

base = Path("/var/log/app")
report = base / "report.txt"
base.mkdir(parents=True, exist_ok=True)

report.write_text("ok
", encoding="utf-8")
print(report.read_text(encoding="utf-8"))

for p in base.glob("*.log"):
    print(p.name, p.stat().st_size)

JSON

import json

data = {"host": "app.local", "ok": True}

with open("state.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

with open("state.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)

Пример: отчёт

from pathlib import Path
from datetime import datetime

def write_report(path, rows):
    lines = [f"# отчёт {datetime.now():%Y-%m-%d %H:%M}", ""]
    for name, status in rows:
        lines.append(f"- {name}: {status}")
    Path(path).write_text("
".join(lines) + "
", encoding="utf-8")

write_report("report.md", [("nginx", "ok"), ("docker", "ok"), ("vpn", "down")])
Атомарная запись

Пиши во временный файл и переименовывай: tmp.replace(target). Так читатель не увидит половину отчёта.
