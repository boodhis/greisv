Обучение

Переменные, типы, условия и циклы Python — база с примерами и таблицей типов.

Python — язык, с которого проще всего начать автоматизацию: читаемый синтаксис, огромная стандартная библиотека, работает на любом сервере. Здесь — база, без которой не двинуться дальше: переменные, типы, ветвления, циклы.

Переменные и типы

Переменная — имя, привязанное к объекту. Тип определяется значением, объявлять его не нужно.

host = "app.local"          # str
port = 8080                 # int
ratio = 0.75                # float
enabled = True              # bool
tags = ["web", "prod"]      # list
cfg = {"port": 8080}        # dict
pair = (1, 2)               # tuple
uniq = {1, 2, 3}            # set
nothing = None              # NoneType
ТипПримерКогда брать
str"nginx"текст, имена, пути
int22порты, счётчики
float1.5метрики, доли
boolTrueфлаги, проверки
list[1, 2]упорядоченный набор, меняется
tuple(1, 2)фиксированная пара
dict{"a": 1}ключ → значение
set{1, 2}уникальные элементы

Условия

Отступы в Python — часть синтаксиса. Тело блока отделяется четырьмя пробелами.

port = 8080
if port < 1024:
    print("привилегированный порт")
elif port == 8080:
    print("типовой веб-порт")
else:
    print("нестандартный порт")

Пустое значение, ноль и пустая строка считаются ложью: if not tags: ... сработает на пустом списке.

Циклы

services = ["nginx", "docker", "sshd"]
for name in services:
    print(f"проверяю {name}")

for i in range(3):
    print(i)  # 0 1 2

n = 0
while n < 3:
    n += 1

Для словаря удобно идти по парам: for k, v in cfg.items(): .... Для списка с индексом — enumerate(services).

Проверка типов

type(x) и isinstance(x, int) — первый для отладки, второй для условий. В продакшене лучше isinstance: он учитывает наследование.
