Обучение

Шпаргалка Git: init, add, commit, log, branch, merge, remote и отмена изменений.

Шпаргалка Git: от init до отмены. Всё, что нужно в ежедневной работе.

Старт

КомандаЧто делает
git initсоздать репозиторий
git clone URLсклонировать
git config --global user.name "..."имя
git config --global user.email "..."почта
git config --global init.defaultBranch mainветка по умолчанию

Состояние и индекс

КомандаЧто делает
git statusчто изменено
git diffнезастейдженные правки
git diff --stagedв индексе
git add fileв индекс
git add -pпо кускам
git add .всё из текущего каталога

Коммиты

КомандаЧто делает
git commit -m "msg"закоммитить
git commit --amendпоправить последний
git log --oneline --graph --decorateкрасивая история
git log -p fileистория файла с диффами
git show <sha>что в коммите
git blame fileкто и когда менял строки

Ветки

КомандаЧто делает
git branchсписок
git branch -aвключая remote
git switch -c featсоздать и перейти
git switch mainперейти
git merge featвлить в текущую
git rebase mainперенести свои коммиты на main
git branch -d featудалить

Remote

КомандаЧто делает
git remote -vсписок remote
git remote add origin URLдобавить
git fetchзабрать без слияния
git pullfetch + merge
git pull --rebasefetch + rebase
git push -u origin mainпервый push
git push --force-with-leaseбезопасный force

Отмена изменений

ЗадачаКоманда
Вернуть файлgit restore file
Убрать из индексаgit restore --staged file
Откатить коммит с сохранением историиgit revert <sha>
Сбросить ветку к коммиту, потеряв правкиgit reset --hard <sha>
Сбросить, оставив правки в рабочем каталогеgit reset --soft <sha>

Stash

git stash        # спрятать
git stash list
git stash pop    # вернуть и удалить из стека
git stash apply  # вернуть, оставив в стеке
git stash drop   # удалить
force только с lease

--force затирает чужие коммиты. Используй --force-with-lease: он упадёт, если кто-то успел запушить.
