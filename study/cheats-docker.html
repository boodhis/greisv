Обучение

Шпаргалка Docker: build, run, exec, logs, compose, чистка и лимиты памяти.

Шпаргалка Docker: образы, контейнеры, compose, чистка. Всё, что нужно в терминале.

Образы

КомандаЧто делает
docker pull nginx:alpineскачать образ
docker imagesсписок
docker build -t app:0.1 .собрать
docker image rm app:0.1удалить
docker tag app:0.1 registry/app:0.1тег для registry
docker push registry/app:0.1запушить
docker history app:0.1слои образа

Контейнеры

КомандаЧто делает
docker run -d --name web -p 8080:80 nginxзапустить
docker psзапущенные
docker ps -aвключая остановленные
docker stop webостановить
docker start webзапустить снова
docker rm webудалить
docker rm -f webубить и удалить

Отладка

КомандаЧто делает
docker logs -f webлоги в реальном времени
docker logs --tail 100 webпоследние 100 строк
docker exec -it web shшелл внутри
docker exec web cat /etc/hostsодна команда
docker inspect webJSON с настройками
docker statsCPU/RAM в реальном времени
docker top webпроцессы контейнера
docker port webпроброс портов

Volumes и сеть

КомандаЧто делает
docker volume lsтома
docker volume create dataсоздать
docker volume rm dataудалить
docker network lsсети
docker network create appnetсоздать
docker network inspect appnetкто подключён

Ограничения памяти и CPU

docker run -d --name app \
    --memory 512m --memory-swap 512m \
    --cpus 1.5 \
    --restart unless-stopped \
    app:0.1

Compose

КомандаЧто делает
docker compose up -dподнять в фоне
docker compose up -d --buildпересобрать и поднять
docker compose psстатус
docker compose logs -f webлоги сервиса
docker compose exec web shзайти внутрь
docker compose downостановить и удалить
docker compose pullобновить образы

Чистка

КомандаЧто делает
docker system dfсколько места занимает
docker system pruneудалить остановленные, сети, кэш
docker system prune -aплюс неиспользуемые образы
docker image prune -aтолько образы
docker volume pruneнеиспользуемые тома
prune -a заденет лишнее

docker system prune -a удалит все образы, которые сейчас не используются контейнерами. Не запускай на прод-хосте без понимания последствий.
