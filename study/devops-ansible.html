Обучение

Ansible: инвентарь, playbook, модули apt/service/copy/template и первый запуск.

Ansible настраивает серверы по описанию: инвентарь, playbook, идемпотентность. Один и тот же playbook поднимает nginx на десяти машинах и не ломается при повторном запуске. Агентов ставить не надо — только SSH и Python.

Инвентарь

# inventory.ini
[web]
app.local ansible_host=192.168.0.10

[db]
db.local ansible_host=192.168.0.20

[all:vars]
ansible_user=deploy
ansible_ssh_private_key_file=~/.ssh/id_ed25519

Проверка связи:

ansible all -i inventory.ini -m ping

Playbook

# site.yml
- name: базовый веб-сервер
  hosts: web
  become: true
  tasks:
    - name: обновить кэш apt
      apt:
        update_cache: true
    - name: поставить nginx
      apt:
        name: nginx
        state: present
    - name: положить конфиг
      copy:
        src: files/nginx.conf
        dest: /etc/nginx/nginx.conf
        mode: "0644"
      notify: reload nginx
    - name: шаблон index
      template:
        src: templates/index.html.j2
        dest: /var/www/html/index.html
    - name: включить сервис
      service:
        name: nginx
        state: started
        enabled: true
  handlers:
    - name: reload nginx
      service:
        name: nginx
        state: reloaded

Роль

Роль — папка с задачами, шаблонами, дефолтами. Раскладка:

roles/nginx/
    tasks/main.yml
    handlers/main.yml
    templates/index.html.j2
    files/nginx.conf
    defaults/main.yml

Подключение:

- hosts: web
  roles:
    - nginx

Первый запуск

ansible-playbook -i inventory.ini site.yml --check
ansible-playbook -i inventory.ini site.yml --diff
ansible-playbook -i inventory.ini site.yml

--check показывает, что изменится, не трогая систему. --diff печатает разницу в файлах. Первый прогон на новом хосте — всегда с ними.

Идемпотентность

Playbook можно запускать сколько угодно раз: если состояние уже нужное, задача ничего не делает. Не пиши shell: ... там, где есть модуль.
