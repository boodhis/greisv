🐍 Python для совсем зелёных

Ты ещё ни разу не писал код? Это курс для тебя. Десять коротких уроков: одна тема, одна задача, один вопрос ИИ-наставнику. Весь курс — один сквозной проект, который растёт с тобой и в конце реально работает на твоём сервере.

Сквозной проект: Healthcheck сервера

Ты строишь программу-«медосмотр» для своего хомлаба (192.168.0.244). Урок 1 — она просто печатает строку. Урок 10 — она читает состояние сервера: дату, свободное место, аптайм — и пишет отчёт в файл. Потом, на курсе «Разработка под Linux», этот же проект превращается в CLI-утилиту, потом в окно, потом в сервис под systemd. Одна программа — весь путь.

Правила ИИ-наставника

Курс идёт в паре с ИИ-моделью. Правило трёх подсказок: ИИ не даёт решение, пока ты не сделал три попытки или не попросил прямо. В каждом уроке — готовые фразы «спроси ИИ». Наставник хвалит конкретно («ты верно обработал пустой список — это типичная ошибка новичка»), а не «молодец».

Урок 1 · Что такое программа

Цель: понять, что такое программа, и запустить свою первую. Время: чтение 10 минут + задание 20–30 минут.

Теория (3 минуты)

Программа — это список команд для компьютера. Как рецепт: «возьми муку → насыпь → размешай». Компьютер тупой и послушный: делает ровно то, что написано, строка за строкой, сверху вниз.

Python — язык, на котором команды пишутся. Он специально похож на английский, чтобы человеку было легче. Первая команда, которую учат все в мире:

print("Привет, мир")

print значит «вывести на экран». Всё в кавычках он показывает тебе в ответ. Кавычки обязательны: это конверт — без них компьютер подумает, что «Привет» это команда, а не текст.

Что нужно (2 минуты)

  • Текстовый редактор на компе или телефоне (подойдёт любой; на сервере можно nano).
  • Файл с именем hello.py — расширение .py говорит «это код на Python».
  • Python на сервере уже есть (проверим заданием). На своём компе, если нет: sudo apt install python3.

Мини-шпаргалка

ЧтоКак
Вывести текстprint("текст")
Вывести числоprint(42)
Пустая строкаprint()
Комментарий (для себя, комп игнорит)# это заметка

Задача

Задание 1. Создай hello.py, который печатает о тебе 3 строки: имя; возраст; одна вещь, которую хочешь уметь через год (например «хочу писать скрипты для сервера»). Между строками — пустая (через print() без кавычек). Внизу — комментарий # мой первый скрипт.

Запуск: в терминале перейди в папку с файлом (cd папка) и набери python3 hello.py. Увидел свои строки — задача сделана.

Если что-то сломалось

  • python: command not found → попробуй python3 (на Linux почти всегда именно так).
  • SyntaxError: invalid syntax → забыл кавычку или скобку: print"Привет" и print("Привет") — разные вещи.
  • NameError: name 'Привет' is not defined → забыл кавычки: компьютер принял «Привет» за команду.
  • Ничего не вывелось → проверь, что запускаешь тот файл, который отредактировал (и что сохранил).

Это не «ты тупой» — через эти ошибки проходит каждый. Они часть обучения.

Спроси ИИ-наставника

1. Объяснение проще: «Объясни урок 1 как пятикласснику. Один пример, без терминов, максимум 5 предложений».
2. Проверка кода: «Вот мой код из урока 1: [вставь]. Найди 2 вещи: что улучшить по стилю и одну типичную ошибку новичка, которую я мог допустить, но не допустил. Не пиши готовый код — только объясни, что и почему».
3. Если застрял: «Мой код: [вставь]. Ошибка в терминале: [вставь]. Что я уже попробовал: [напиши]. Дай подсказку-вопрос, а не решение — хочу догадаться сам».
4. Проверка понимания: «Задай мне 3 вопроса по уроку 1, чтобы проверить, что я понял. Жди моих ответов».

Self-check (честно себе)

1. Что делает print() — одним предложением, своими словами? 2. Почему текст всегда в кавычках? 3. Что будет, если убрать кавычки в print(Привет)?
Ответил на 3-й «будет ошибка / подумает, что это команда» — урок закрыт.

Слова дня (повтор через 1/3/7 дней)

Программа — список команд для компьютера · Python — язык, на котором эти команды пишут · print() — команда «вывести на экран».

Урок 2 · Инструменты: папка проекта, uv, VS Code

Цель: создать проект healthcheck/ современным способом (uv вместо возни с pip/venv).

Настоящие программы живут в своей папке со своей «упаковкой зависимостей». Современный инструмент 2026 — uv: одна команда создаёт проект, ставит Python, запускает — без боли. Сейчас просто копируй команды, «почему» разберём в курсе про Linux.

# включи сервер, открой терминал
sudo apt install uv            # на своём компе — эта же команда, или у тебя macOS/Windows — спроси ИИ
uv init healthcheck            # папка проекта
cd healthcheck
uv run python3 hello.py        # запуск скрипта через uv

VS Code — удобный редактор с подсветкой кода (на сервере достаточно nano, но на компе VS Code сильно облегчит жизнь). Урок, если честно, скучный, но нужный: с этого момента весь курс мы живём в этом проекте.

Урок 3 · Переменные и типы

Цель: классь данные в переменные и отличать текст от числа.

Переменная — коробочка с именем. = в Python значит не «равно», а «положи в коробочку». Числа и текст — разные типы: 30 это число, "30" — текст, и 30 + 1 будет 31, а "30" + "1" — «301».

имя = "Иван"
день = 21
месяц = "сентябрь"
print(имя, день, месяц)

Урок 4 · Ввод и f-строки

Цель: спрашивать пользователя и красиво подставлять данные в текст.

input() спрашивает и ждёт ответ с клавиатуры. Он всегда возвращает текст; чтобы получить число — оберни в int(...). f-строки собирают текст с данными: перед кавычками f, значения — в фигурных скобках.

имя = input("Как зовут сервер? ")
лет = int(input("Сколько лет серверу? "))
print(f"{имя} работает уже {лет} лет")

Урок 5 · Условия if/else

Цель: программа принимает решения.

if — «если»; если условие истинно, выполняется блок под ним, иначе else. Сравнения: ==, !=, >, <, >=, <=. Отступы обязательны: они показывают, где блок.

место = float(input("Сколько гигабайт свободно? "))
if место < 5:
    print("Место заканчивается!")
elif место < 20:
    print("Уже пора почистить…")
else:
    print("Всё в порядке.")

Спроси ИИ: «Почему программа пошла в else, хотя я ввёл то же число?» — сравни тип числа. «Когда и почему нужен elif, а когда два if?»

Self-check

Чем == отличается от =? Что будет, если забыть отступ? Сколько раз можно поставить elif подряд?

Слова дня

Условие — выражение «да/нет» · Блок — группа строк, которые исполняются вместе · elif — «иначе если», ещё одна проверка в цепочке.

Урок 6 · Списки

Цель: хранить много значений и проходить по ним.

Список — коробка со значениями по порядку: ["cpu", "диск", "сеть"]. Номер элемента — индекс, начинается с 0: список[0]. .append() добавляет, цикл for x in список проходит по всем.

проверки = ["CPU", "диск", "сеть"]
проверки.append("память")
for что in проверки:
    print("Проверяю:", что)

Урок 7 · Циклы и словари

Цель: while и словарь «ключ → значение».

while повторяет, пока условие истинно. Словарь хранит пары «имя: значение»: {"место": 10, "cpu": 4}. Обращаешься по ключу, а не по номеру.

настройки = {"порог_места": 5, "имя_сервера": "iva"}
ответ = ""
while ответ != "стоп":
    ответ = input("Меню: cpu/диск/стоп → ")
    if ответ == "cpu":
        print("CPU:", настройки.get("cpu", "нет данных"))

Урок 9 · Файлы: Healthcheck пишет отчёт

Цель: сохранить результат между запусками.

open() + with открывает файл и сам закрывает. pathlib.Path — современный способ работы с путями.

from pathlib import Path

путь = Path("healthcheck") / "отчёт.txt"
with open(путь, "a") as f:       # "a" = добавить в конец
    f.write("2026-09-21: всё ок\n")

with open(путь) as f:
    print(f.read())

Урок 10 · Ошибки и финал: Healthcheck v1

Цель: читать ошибки как информацию и собрать готовый проект.

Ошибки Python — это подсказки с адресом: «Файл x.py, строка 12, ошибка: ...». Читай последнюю строку сообщения. try/except ловит ошибки и продолжает работу — например, если файл отчёта ещё не существует.

try:
    with open("healthcheck/отчёт.txt") as f:
        print(f.read())
except FileNotFoundError:
    print("Отчётов пока нет — это нормально для первого запуска")
