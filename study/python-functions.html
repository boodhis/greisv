Обучение

Функции Python: def, аргументы, return, *args/**kwargs, модули и main с примерами.

Функция — способ не повторять один и тот же код и давать ему имя. Без функций скрипт на 50 строк превращается в кашу, которую через неделю невозможно читать. Здесь — синтаксис, аргументы, возврат и как вынести код в модуль.

Объявление и вызов

def ping(host):
    return f"ping {host}"

print(ping("app.local"))

def — объявление, return — выход с результатом. Без return функция возвращает None.

Параметры и аргументы

def deploy(service, env="prod", dry=False):
    if dry:
        return f"[dry] {service} -> {env}"
    return f"deploy {service} -> {env}"

deploy("nginx")              # env="prod"
deploy("nginx", env="stage")
deploy("nginx", dry=True)

Значения по умолчанию вычисляются один раз — не клади туда список или словарь. Для «пустого» значения используй None:

def add(items=None):
    items = items or []
    items.append(1)
    return items

*args и **kwargs

def run(*args, **kwargs):
    print(args)    # tuple позиционных
    print(kwargs)  # dict именованных

run("a", "b", timeout=5, retries=3)

Звёздочки удобны для обёрток и логгеров: принимаешь что угодно и передаёшь дальше.

Модули и import

Файл utils.py — это модуль. Импортируй его из соседнего файла:

# utils.py
def load(path):
    ...

# main.py
import utils
from utils import load

utils.load("cfg.json")
load("cfg.json")

__main__

Классический шаблон: файл можно запускать как скрипт и импортировать как модуль.

def main():
    print("run")

if __name__ == "__main__":
    main()
Не клади логику в импорт

Всё, что выполняется на уровне модуля, сработает при import. Побочные эффекты — только внутри main().
