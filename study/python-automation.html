Обучение

Автоматизация в Python: argparse, логирование, cron и systemd-timer с примерами.

Скрипт, который запускается руками, — это хобби. Скрипт, который запускается по расписанию и пишет лог, — это автоматизация. Здесь: argparse, логирование, cron и systemd-timer.

argparse

import argparse

def main():
    p = argparse.ArgumentParser(description="Проверка сервисов")
    p.add_argument("--host", default="app.local")
    p.add_argument("--timeout", type=int, default=5)
    p.add_argument("--dry", action="store_true")
    args = p.parse_args()
    print(args.host, args.timeout, args.dry)

if __name__ == "__main__":
    main()

Запуск: python check.py --host app.local --timeout 10 --dry. --help собирается сам.

Логирование

import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(message)s",
    filename="/var/log/checker.log",
)
log = logging.getLogger("checker")

log.info("старт")
log.warning("сервис %s не отвечает", "vpn")

Не используй print в продакшене: логирование даёт уровни, время и запись в файл без ручной возни.

cron

Простой способ — строка в crontab. Открой crontab -e и добавь:

# каждые 5 минут
*/5 * * * * /usr/bin/python3 /opt/checker/check.py >> /var/log/checker.cron.log 2>&1

# каждый день в 03:15
15 3 * * * /usr/bin/python3 /opt/checker/backup.py

Пять полей: минута, час, день, месяц, день недели. 2>&1 важен — иначе ошибки уйдут в никуда.

systemd-timer

Гибче cron: юнит-файл и таймер отдельно, логи идут в journald.

# /etc/systemd/system/checker.service
[Unit]
Description=Service checker

[Service]
Type=oneshot
ExecStart=/usr/bin/python3 /opt/checker/check.py
User=root

# /etc/systemd/system/checker.timer
[Unit]
Description=Run checker every 5 min

[Timer]
OnBootSec=2min
OnUnitActiveSec=5min
Unit=checker.service

[Install]
WantedBy=timers.target

Активация:

sudo systemctl daemon-reload
sudo systemctl enable --now checker.timer
systemctl list-timers | grep checker
journalctl -u checker.service -n 50
