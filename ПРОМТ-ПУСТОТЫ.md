# Промт: заполнение пустот «Цифровой Крепости»

> Промт для большой модели. Кинь её выводы агенту — он вставит контент в страницы,
> прогонит `tests/test_site.py` и отдаст дев-версию.

---

Ты пишешь контент для статического сайта «Цифровая Крепость» (электронные заметки своими руками: homelab, Linux, обучение). Сайт — офлайн, без трекеров, без внешних ресурсов, «своими руками, с резервными копиями». Тон: прямой, на «ты», практичный, без воды, без «добро пожаловать», без эмодзи, без саморекламы. Пишем только содержимое блока <main>. Head, меню, хлебные крошки, h1 и <p class="desc"> уже существуют — их не менять.

СТИЛЬ РАЗМЕТКИ (доступные теги):
- <h2> секции, <h3> подразделы
- <p> короткие абзацы
- <ul>/<ol>/<li> со <strong> и <code>
- <table> с <thead><th> только для сравнений/шпаргалок
- <pre><code> для команд и кода (блоки Ubuntu/Linux, реальные примеры)
- <div class="callout callout-note">...</div> и callout-warning
  (внутри: <div class="callout-t">Заголовок</div><div class="callout-body"><p>...</p></div>)
- <hr> для разделения больших частей
- Внутренние ссылки между страницами сайта — можно; снаружи — нельзя.
- Каждую страницу начинай с краткого «Зачем это» (2-3 строки), затем пошаговые инструкции/примеры. Объём: курсы и материалы 250–450 слов с примерами кода; шпаргалки — плотные таблицы/списки команд (30–60 команд); homelab 250–350 слов.

ФОРМАТ ВЫВОДА — строго по одному блоку на страницу, в начале блока путь:
### study/python-basics.html
[содержимое <main>, готовый HTML]
Между блоками — строка из пяти дефисов. В самом конце, отдельным блоком
### META, выпиши новый meta description для каждой страницы:
- путь — новый description (1 предложение до 120 символов).
