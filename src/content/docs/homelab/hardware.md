## Выбор железа для Homelab

### Минимальные требования

| Компонент | Минимум | Рекомендация |
|-----------|---------|--------------|
| **Процессор** | 2 ядра | 4+ ядер |
| **ОЗУ** | 4 ГБ | 8+ ГБ |
| **Диск** | 120 ГБ SSD | 240+ ГБ SSD |
| **Сеть** | 100 Мбит | 1 Гбит |

### Варианты железа

#### 1. Старый ноутбук (как у нас)
- **Плюсы**: уже есть, есть батарея (ИБП), экран
- **Минусы**: ограниченные возможности апгрейда
- **Наш пример**: Acer Extensa 2520G (i5-6200U, 8GB RAM)

#### 2. Mini-PC (Intel NUC и подобные)
- **Плюсы**: компактный, тихий, экономичный
- **Минусы**: нужно покупать
- **Примеры**: Intel NUC, Beelink, MinisForum

#### 3. Б/У сервер
- **Плюсы**: мощный, много разъёмов
- **Минусы**: шумный, прожорливый
- **Примеры**: Dell PowerEdge, HP ProLiant

#### 4. Raspberry Pi
- **Плюсы**: дешёвый, маленькое потребление
- **Минусы**: мало мощности, ARM-архитектура

### Что важно?

1. **Тишина** — сервер работает 24/7, шум будет раздражать
2. **Потребление** — электричество стоит денег
3. **Расширяемость** — слоты для RAM, дисков
4. **Надёжность** — SSD вместо HDD для системного диска

### Наш опыт

Мы использовали старый ноутбук Acer Extensa 2520G:
- **Процессор**: Intel Core i5-6200U (2 ядра / 4 потока)
- **ОЗУ**: 8 ГБ DDR3
- **Диски**: 240 ГБ SSD + 4 внешних HDD/SSD
- **Сеть**: WiFi (потом добавили Ethernet)

Работает отлично! Старое железо — не приговор.
