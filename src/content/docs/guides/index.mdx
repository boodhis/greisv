## Гайды по Linux

Здесь собраны пошаговые инструкции для решения типичных задач.

### Что найдёшь?

| Раздел | Описание |
|--------|----------|
| **[Диски и SMART](/guides/disk-health)** | Мониторинг состояния дисков |
| **[Диагностика](/guides/diagnostics)** | Поиск и решение проблем |
| **[Бекапы](/guides/backup)** | Резервное копирование данных |
| **[SSH](/guides/ssh)** | Удалённый доступ к серверу |
| **[Терминал](/guides/terminal)** | Полезные команды и утилиты |
| **[Wi-Fi фикс](/guides/wifi-fix)** | Решение проблем с Wi-Fi |

| **[journalctl](/guides/journalctl)** | Работа с системными логами |

### Как пользоваться?

1. **Найди нужный раздел** в меню слева
2. **Следуй инструкциям** пошагово
3. **Копируй команды** и вставляй в терминал
4. **Читай пояснения** — они помогут понять что происходит

### Советы

- **Читай предупреждения** — некоторые команды могут повредить данные
- **Делай бекапы** перед важными изменениями
- **Проверяй команды** — убедись что понимаешь что делаешь
- **Спрашивай помощь** — в GitHub Issues или сообществе
