## Сервер: Acer Extensa 2520G

### Характеристики

| Параметр | Значение |
|----------|----------|
| **Хост** | `iva` (Acer, Ubuntu Server 24.04) |
| **IP** | `192.168.0.244` (WiFi `wlp3s0`) |
| **Пользователь** | `iva` |
| **SSH** | `ssh iva@192.168.0.244` (порт 22) |
| **Процессор** | Intel Core i5-6200U (2 ядра / 4 потока) |
| **ОЗУ** | 8 ГБ DDR3 |
| **Диски** | 5 накопителей (см. ниже) |

### Диски

| Точка монтирования | Устройство | Объём | Назначение |
|-------------------|------------|-------|------------|
| `/` | sda (SSD) | 240 ГБ | Системный |
| `/mnt/storage` | sdb (HDD) | 1 ТБ | Файлы, бекапы |
| `/mnt/2tb` | sdd (HDD) | 2 ТБ | Музыка, видео |
| `/mnt/700` | sde (HDD) | 700 ГБ | Фильмы, сериалы |
| `/mnt/serials` | sdc (HDD) | 500 ГБ | Сериалы |

### Полезные команды

#### Статус сервисов
```bash
systemctl is-active minidlna transmission-daemon mosquitto
```

#### Проверка температуры
```bash
cat /sys/class/thermal/thermal_zone2/temp
```

:::tip[Разбор команды]
Показывает температуру процессора в миллиградусах. Раздели на 1000 для °C.
:::

#### Проверка SMART дисков
```bash
sudo smartctl -H /dev/sda
```

:::tip[Разбор команды]
`smartctl` — утилита для мониторинга состояния дисков. `-H` показывает общий статус.
:::

#### Просмотр логов
```bash
journalctl -u docker.service --since "1 hour ago"
```

:::tip[Разбор команды]
Показывает логи Docker за последний час.
:::

### Бекапы

Ежедневный бекап конфигов (cron, 04:00):

```bash
# Скрипт: /home/iva/backup/backup.sh
# Куда: /mnt/storage/backups/ivan-config-<дата>.tar.gz
# Что: конфиги, compose-файлы, скрипты
```

Ручной запуск:

```bash
sudo /home/iva/backup/backup.sh
```
