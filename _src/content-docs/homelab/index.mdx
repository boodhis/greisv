## Что такое Homelab?

**Homelab** — это домашняя лаборатория для изучения технологий. Это как научная лаборатория, но для компьютерных наук.

### Зачем нужен homelab?

| Цель | Пример |
|------|--------|
| **Обучение** | Изучение Linux, Docker, сетей |
| **Эксперименты** | Тестирование нового ПО без риска |
| **Автоматизация** | Умный дом, бекапы, мониторинг |
| **Безопасность** | Хранение данных под своим контролем |
| **Экономия** | Бесплатные альтернативы облачным сервисам |

### Концепция "Цифровой Крепости"

Наш homelab — это не просто набор компьютеров. Это **система**:

```
┌─────────────────────────────────────────────────┐
│                 Цифровая Крепость               │
├─────────────────────────────────────────────────┤
│  🖥️ Сервер         │  💾 Диски                  │
│  ├─ Ubuntu Server   │  ├─ Системный (240G)      │
│  ├─ Docker          │  ├─ Хранилище (1TB)       │
│  └─ Сервисы         │  ├─ Архив (2TB)           │
│                     │  └─ Флешка (30G)           │
├─────────────────────────────────────────────────┤
│  🌐 Сеть            │  🔒 Безопасность          │
│  ├─ WiFi            │  ├─ Firewall              │
│  ├─ SSH             │  ├─ Бекапы                │
│  └─ VPN (будущее)   │  └─ Мониторинг            │
└─────────────────────────────────────────────────┘
```

### Принципы

1. **Простота** — используем только проверенные решения
2. **Надёжность** — всё должно работать после перезагрузки
3. **Документация** — каждое действие описано
4. **Открытый код** — всё можно скопировать

### Что мы строим?

Наш homelab включает:

- **Сервер**: Ubuntu Server 24.04 на старом ноутбуке Acer
- **Сервисы**: Docker контейнеры для различных задач
- **Хранилище**: 5 дисков общим объёмом 4 ТБ
- **Мониторинг**: отслеживание состояния системы
- **Бекапы**: регулярное копирование важных данных

### Как начать?

1. **Выбери железо** — подойдёт даже старый компьютер
2. **Установи Ubuntu** — следуй инструкциям в разделе "Старт"
3. **Настрой сервисы** — начни с простых (Samba, Docker)
4. **Документируй** — записывай что делаешь
