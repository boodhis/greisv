## ESP32: Прототипирование

Параллельно с сервером осваиваю разработку на микроконтроллерах **ESP32**. Это процесс, а не цель — маленькая плата, которая умеет WiFi, Bluetooth и радио, открывает огромный мир устройств: от статус-панели до умного датчика.

Первым устройством стал **Heltec WiFi LoRa 32 V3** — панель статуса нашего сервера.

### Почему ESP32

- **Умеет WiFi и BLE** — легко общается с сервером и телефоном
- **Собирается из YAML** через ESPHome — не нужно писать C++ с нуля
- **Дёшево и доступно** — идеально для экспериментов
- **Много GPIO** — подключай датчики, кнопки, экраны

### Наша плата: Heltec V3

Построена на чипе **ESP32-S3**:
- Встроенные **WiFi**, **LoRa** (дальнее радио) и **BLE**
- **OLED-экран** 128x64
- Кнопка **PRG** и светодиод
- Много свободных пинов для экспериментов

#### Ключевые пины

| Пин | Назначение |
|-----|-----------|
| GPIO0 | Кнопка PRG |
| GPIO35 | Встроенный LED |
| GPIO36 | Питание OLED |
| GPIO17/18 | I2C (OLED) |
| GPIO8/9/14 | SPI (радио LoRa) |

### Как это работает: ESPHome

ESPHome превращает **YAML-конфиг** в готовую прошивку. Описал, что хочу — получил `.bin`, залил на плату.

```
yaml-конфиг → компилятор → firmware.bin → залить на плату
```

Наш конфиг `server-panel.yaml`:
- `wifi` — вход платы в сеть
- `mqtt` — обмен данными с сервером
- `text_sensor` — статус сервера из MQTT
- `display` — вывод на OLED
- `esp32_ble_server` — раздача статуса по Bluetooth

> **Lambda** — это вставки C++ прямо в yaml, там где обычных настроек не хватает. Так можно рисовать на экране, считать, отправлять данные.

### Прошивка по USB

1. Подключаем плату **кабелем с данными** (не только зарядным!)
2. Плата появляется как `/dev/ttyUSB0`
3. Правим yaml → **Скомпилировать** → **Прошить**

:::warning[Осторожно]
Не выдёргивай кабель во время прошивки — можно повредить загрузчик.
:::

### Метод обучения

1. **Маленький шаг** — одна вещь за раз, а не всё сразу
2. **Компилируй** — проверяй, что собирается без ошибок
3. **Прошивай и смотри** — что изменилось на плате
4. **Ломай осознанно** — чини по логу, так учишься быстрее

### Идеи следующего шага

- Кнопка на плате → действие на сервере
- Датчик температуры → в MQTT
- Светодиодная индикация по статусу
- Вторая страница на OLED
- LoRa-сообщение на вторую плату
