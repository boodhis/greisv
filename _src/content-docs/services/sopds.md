## SOPDS: Библиотека книг

**SOPDS** (Simple OPDS Server) — это персональный сервер электронных книг с веб-интерфейсом. Удобный способ читать и скачивать книги с любого устройства в домашней сети.

### Что это даёт

- 📚 Доступ к коллекции книг с телефона, планшета, компьютера
- 🔍 Поиск по авторам, жанрам, названиям
- 📥 Скачивание в FB2, EPUB, TXT
- 🌐 Веб-интерфейс и OPDS-каталог для читалок

### Установка через Docker

```yaml
services:
  sopds:
    image: zveronline/sopds:latest
    platform: linux/amd64
    container_name: sopds
    ports:
      - "8081:8001"
    volumes:
      - /mnt/minis/flibusta:/library:ro
      - ./sopds_db:/var/lib/sopds
    environment:
      - SOPDS_LANGUAGE=ru
    restart: always
```

:::tip[Разбор конфига]
- `platform: linux/amd64` — обязателен для больших библиотек
- `ports: 8081:8001` — внешний порт 8081, внутренний 8001
- `volumes` — папка с книгами и база данных
:::

### Критические настройки

После запуска зайди в **Admin → Constance** и настрой:

| Параметр | Значение | Зачем |
|----------|----------|-------|
| `SOPDS_ROOT_LIB` | `/library` | Путь к книгам внутри контейнера |
| `SOPDS_INPX_ENABLE` | `True` | Использовать .inpx индекс (без этого 300ГБ сканируются вечность) |
| `SOPDS_INPX_LANGS` | `ru, ru-RU` | Фильтр языков |
| `SOPDS_ZIPCODEPAGE` | `cp866` | Русские имена в ZIP |
| `SOPDS_MAXITEMS` | `20` | Лимит на страницу |
| `SOPDS_SPLITITEMS` | `100` | Ускорение меню |

### Полезные команды

```bash
# Принудительный запуск сканера
docker exec -d sopds python3 manage.py sopds_scanner scan

# Проверка нагрузки
htop | grep sopds

# Права доступа
sudo chmod -R 755 /mnt/minis/flibusta
```

:::tip[Разбор команды]
- `docker exec` — выполнить команду в запущенном контейнере
- `manage.py sopds_scanner scan` — запустить сканирование библиотеки
- `htop` — интерактивный диспетчер задач
:::
