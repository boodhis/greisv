## Диагностика Linux

Когда что-то не работает, нужно правильно диагностировать проблему. Вот основные инструменты.

### Проверка системных ресурсов

#### Загрузка процессора

```bash
# Красивый мониторинг
htop

# Или более простой
top
```

:::tip[Разбор команды]
`htop` — интерактивный диспетчер задач. Показывает загрузку CPU, памяти, процессы.
:::

#### Память

```bash
free -h
```

:::tip[Разбор команды]
Показывает количество всей, используемой и свободной оперативной памяти.
:::

#### Диски

```bash
# Занятое место
df -h

# Какие папки больше всего
du -sh /* 2>/dev/null | sort -h
```

:::tip[Разбор команды]
- `df -h` — показывает занятое место на дисках
- `du -sh` — размер директорий
- `sort -h` — сортировка по размеру
:::

### Проверка сети

```bash
# Есть ли интернет?
ping -c 4 google.com

# Какие порты открыты?
sudo ss -tulpn

# Какие интерфейсы есть?
ip a
```

:::tip[Разбор команды]
- `ping -c 4` — отправить 4 пакета
- `ss -tulpn` — показать открытые порты и процессы
- `ip a` — показать сетевые интерфейсы
:::

### Просмотр логов

```bash
# Ошибки текущей загрузки
journalctl -p 3 -xb

# Логи конкретного сервиса
journalctl -u docker.service --since "1 hour ago"

# Все логи (через less)
journalctl | less
```

:::tip[Разбор команды]
- `-p 3` — приоритет ошибок (3 = error)
- `-xb` — текущая загрузка
- `-u` — логи конкретного сервиса
- `--since` — за последний час
:::

### Анализ загрузки

```bash
# Общее время загрузки
systemd-analyze

# Какие сервисы тормозят
systemd-analyze blame

# Критические зависимости
systemd-analyze critical-chain
```

:::tip[Разбор команды]
Помогает понять, почему Linux долго загружается и какой сервис "тормозит".
:::

### Проверка процессов

```bash
# Дерево процессов
ps auxf

# Поиск процесса
ps aux | grep -i "имя_процесса"

# Убить процесс
kill <PID>
kill -9 <PID>  # Принудительно
```

:::tip[Разбор команды]
- `ps auxf` — показать все процессы в виде дерева
- `grep` — фильтрация по имени
- `kill -9` — принудительное завершение
:::

### Проверка сервисов

```bash
# Статус сервиса
systemctl status <сервис>

# Все запущенные сервисы
systemctl list-units --type=service --state=running

# Все failed сервисы
systemctl --failed
```
