## Бекапы: Защита данных

**Бекап** — это копия важных данных. Если диск сломается или файлы удалят случайно, бекап спасёт.

### Правило 3-2-1

- **3** копии данных
- **2** разных типа носителей
- **1** копия вне дома

### Простой бекап через rsync

```bash
# Бекап домашней директории
rsync -av --progress /home/iva/ /mnt/storage/backups/home/

:::tip[Разбор команды]
- `rsync` — утилита для синхронизации файлов
- `-a` — архивный режим (сохраняет права, даты)
- `-v` — подробный вывод
- `--progress` — показывать прогресс
:::

### Бекап через tar

```bash
# Создание архива
tar -czvf /mnt/storage/backups/home-$(date +%Y%m%d).tar.gz /home/iva/

# Извлечение архива
tar -xzvf backup.tar.gz -C /home/iva/
```

:::tip[Разбор команды]
- `-c` — создать архив
- `-z` — сжать gzip
- `-v` — подробный вывод
- `-f` — имя файла
:::

### Автоматический бекап (cron)

```bash
# Редактирование cron
crontab -e

# Добавь строку (бекап каждый день в 3:00)
0 3 * * * rsync -av /home/iva/ /mnt/storage/backups/home/
```

:::tip[Разбор команды]
- `0 3 * * *` — каждый день в 3:00
- `crontab -e` — редактирование расписания задач
:::

### Бекап базы данных

#### PostgreSQL

```bash
# Бекап базы
pg_dump -U username database_name > backup.sql

# Восстановление
psql -U username database_name < backup.sql
```

#### SQLite

```bash
# Простое копирование файла
cp /path/to/database.db /backup/path/
```

### Проверка бекапов

```bash
# Проверить размер бекапов
du -sh /mnt/storage/backups/*

# Проверить последний бекап
ls -la /mnt/storage/backups/
```
