🏗 Манифест Цифровой Крепости

Ни одной подписки. Ни одного трекера. Всё на своём.

Почему этот сайт существует и как он устроен. Короткая версия: бесплатно, открыто, офлайн, своими руками — с резервными копиями, понятными границами и правом на выход.

Принципы

🆓 Бесплатно

Ни одной платной подписки за софт и сервисы. «Бесплатно» здесь — про свободу и про цену: железо и электричество — это не подписка. Это честная стоимость независимости.

🔓 Открытый код

Весь исходник на GitHub. Можно форкнуть, проверить, переиспользовать. Открытый код — это и «посмотреть», и «убедиться», и «починить».

📴 Работает офлайн

Сайт и приложения доступны без интернета после первого визита. Service Worker кеширует то, что уже видел.

🧑‍🔬 Своими руками

Каждый пример проверен на реальном сервере этого дома. Если что-то не проверено на своём железе — это предположение, а не документация.

🛡 Приватность по умолчанию

Ни рекламы, ни трекеров, ни аналитики, ни cookie-баннеров. Мне не нужно знать, кто ты.

🔐 Безопасность

Крепость без стен — не крепость. Обновления, TLS, SSH-ключи, 2FA, firewall, минимальные права, секреты не в Git.

💾 Резервное копирование

Данные без копии — временные. Правило 3-2-1: три копии, два носителя, одна вне дома.

🧩 Модульность

Каждый сервис делает одно хорошо. Меньше связности — меньше точек отказа.

🔁 Воспроизводимость

Конфиги в Git, стек описывается, а не живёт «на том сервере, который случайно настроил полгода назад».

📚 Документация

Не задокументировано — не существует. README, runbook, схема сети, список сервисов.

🧭 Свобода выхода

Никакого вендор-лока. Данные экспортируются в открытые форматы. Если сервис надоест — его можно заменить.

♻️ Честная цена железа

Железо, электричество, шум, износ, e-waste — это реальная цена, и мы её не прячем. Она всё равно честнее вечной аренды чужого облака.

🌱 Энергия и тишина

Homelab не должен гудеть как серверная. Энергоэффективность и уровень шума — часть архитектуры.

Это возможно — и в России

Всё, из чего собран сайт и homelab, — бесплатное открытое ПО: Linux, Docker, Git, GitHub Pages. Он работает в том числе в России: без зарубежных платных подписок, оплатив только «железо» и электричество.

  • Статический сайт хостится бесплатно на GitHub Pages — единственное «облако» в проекте, во всём остальном всё своё.
  • Сервисы крутятся в Docker на собственном homelab-сервере.
  • Обновления — обычный git push.
  • Проект доказывает: полноценное обучение и домашняя инфраструктура не требуют платных подписок никому.

🧱 Границы крепости: чего здесь нет

Важно не только то, что в крепости есть, но и то, чего мы сознательно туда НЕ пускаем.

  • Платных подписок — ни одной, даже «недорогой».
  • Рекламы, трекеров, аналитики, cookie-баннеров.
  • Мобильных приложений в App Store / Google Play (основное — в браузере).
  • SaaS, работающих «просто так» за счёт твоих данных.
  • Закрытых форматов и вендор-лока — Windows-only инструментов, проприетарных драйверов, «умных» устройств, требующих облако производителя для базовых функций.
  • Секретов в Git — пароли и токены живут в локальном файле.

Офлайн — с оговоркой

Сайт работает офлайн после первого визита: Service Worker кеширует то, что уже видел. Прогресс тренажёра живёт в localStorage — при очистке данных исчезнет. Поэтому в тренажёре есть экспорт/импорт прогресса в JSON: сохраняй перед чисткой браузера.

Правило крепости

Если для задачи нужен платный сервис — задача либо решается открытым софтом, либо не решается вовсе. Любая платная подписка в проекте — ошибка.

Мини-чеклист крепости

  • ☑ Нет платных подписок.
  • ☑ Нет трекеров и аналитики.
  • ☑ Есть экспорт данных (JSON в тренажёре, открытые форматы везде).
  • ☑ Есть резервная копия и память о восстановлении.
  • ☑ Обновления — обычный git push.
  • ☑ Секреты не в Git.
  • ☑ Понятны компромиссы.
  • ☑ Есть план переезда, если внешний сервис станет недоступен.
