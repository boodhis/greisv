🏗 Манифест Цифровой Крепости

Почему этот сайт существует и как он устроен. Короткая версия: бесплатно, открыто, офлайн, самому.

Принципы

🆓 Бесплатно

Ни одной платной подписки, никакой рекламы и трекеров.

🔓 Открытый код

Весь исходник на GitHub. Можно форкнуть, проверить, переиспользовать.

📴 Работает офлайн

Сайт — это статика + легковесные скрипты. Без интернета контент доступен.

🧑‍🔬 Сделано самому

Каждый пример проверен на реальном сервере этого дома. Никакой «воды из методичек».

Это возможно — и в России

Всё, из чего собран сайт и homelab, — бесплатное открытое ПО: Linux, Docker, Git, GitHub Pages. Он работает в том числе в России: без зарубежных платных сервисов, и оплатив только «железо» и электричество.

  • Статический сайт хостится бесплатно на GitHub Pages.
  • Сервисы крутятся в Docker на своём homelab-сервере.
  • Обновления — обычный git push.
  • Проект доказывает: полноценное обучение и домашняя инфраструктура не требуют платных подписок никому.
