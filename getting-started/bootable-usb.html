Создание загрузочной флешки

Для установки Ubuntu Server нужна загрузочная флешка. Вот два способа её создать.

Способ 1: Через файловый менеджер (самый быстрый)

Этот способ появился в свежих версиях Ubuntu — прямо во встроенном файловом менеджере.

  1. Подключи флешку к компьютеру
  2. Найди на рабочем столе свой ISO-образ (файл с серверной Ubuntu)
  3. Кликни по нему правой кнопкой мыши
  4. В выпадающем меню выбери «Открыть с помощью» → «Disk Image Writer»
  5. Откроется маленькое окошко. Проверь, что в поле «Destination» выбрана твоя флешка, а не жесткий диск!
  6. Нажми «Start restoring...» и введи пароль

Через пару минут флешка будет готова.

Способ 2: Через программу «Создание загрузочного диска»

Это классическая утилита Ubuntu:

  1. Нажми клавишу Win (Super) и в поиске начни вводить: «Создание загрузочного диска»
  2. Запусти программу
  3. В верхнем поле «Source disc image» нажми «Other» и выбери свой ISO-файл
  4. В нижнем поле «Disk to use» выбери свою флешку — обязательно проверь объём
  5. Нажми «Make Startup Disk» и подтверди действие

Способ 3: Через терминал (для продвинутых)

Если графические способы не работают:

# Узнай номер флешки
lsblk

# Запиши образ (ЗАМЕНИ /dev/sdX на свою флешку!)
sudo dd if=ubuntu-24.04-live-server-amd64.iso of=/dev/sdX bs=4M status=progress

Внимание!

Команда dd ПОЛНОСТЬЮ СОТРЁТ всё на флешке. Убедись что выбрал правильное устройство!

Разбор команды

  • lsblk — показывает все блочные устройства (диски, флешки)
  • dd — утилита для побайтового копирования
  • if= — input file (входной файл)
  • of= — output file (выходное устройство)
  • bs=4M — размер блока 4 мегабайта
  • status=progress — показывать прогресс

Важное предупреждение

Перед началом убедись, что на ней нет ничего нужного, и что ты выбрал именно флешку, а не свой основной жесткий диск.

Как проверить что флешка работает?

  1. Вставь флешку в компьютер
  2. Перезагрузи компьютер
  3. Нажми клавишу вызова меню загрузки (обычно F12)
  4. Выбери загрузку с флешки

Если появилось меню установки Ubuntu — всё работает!

Эти инструкции работают для Ubuntu 24.04 и других дистрибутивов Linux.
