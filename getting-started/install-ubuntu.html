Установка Ubuntu Server 24.04

Эта инструкция поможет установить Ubuntu Server на любой компьютер. Процесс занимает 15-30 минут.

Что нужно?

  • Компьютер (подойдёт старый ноутбук)
  • Флешка 8 ГБ
  • Интернет (для загрузки образа)
  • Терпение :)

Шаг 1: Скачивание образа

  1. Перейди на ubuntu.com/download/server
  2. Скачай Ubuntu Server 24.04 LTS (версия с долгосрочной поддержкой)
  3. Получится файл ubuntu-24.04-live-server-amd64.iso (~2 ГБ)

Шаг 2: Создание загрузочной флешки

Как создать загрузочную флешку?

Смотри подробную инструкцию в разделе Загрузочная флешка

Шаг 3: Загрузка с флешки

  1. Вставь флешку в компьютер
  2. Перезагрузи компьютер
  3. Нажми клавишу вызова меню загрузки:
- F12 — для большинства ноутбуков - F2 или Del — для настроек BIOS - Esc — для некоторых моделей
  1. Выбери загрузку с флешки (USB)

Шаг 4: Процесс установки

Язык и клавиатура

  • Выбери Russian или English (рекомендуется English для сервера)
  • Раскладка клавиатуры: Russian или English US

Сеть

  • Если есть Ethernet — подключи кабель
  • Wi-Fi потребуется настроить позже

Разметка дисков

Для простоты выбери Use an entire disk: - Это автоматически разделит диск - Для опытных пользователей: ручная разметка

Профиль

  • Your name: твоё имя
  • Your server's name: имя сервера (например, homelab)
  • Username: логин (например, iva)
  • Password: пароль

SSH

  • Обязательно поставь галочку Install OpenSSH server
  • Это позволит подключаться удалённо

Дополнительные пакеты

Можно выбрать: - Docker - PostgreSQL - Prometheus - Или пропустить (установим позже)

Шаг 5: Первое подключение

После установки перезагрузись и войди под своим логином.

Проверка сети

ip a

Разбор команды

ip a — показывает все сетевые интерфейсы и их IP-адреса. a — сокращение от address.

Обновление системы

sudo apt update && sudo apt upgrade -y

Разбор команды

  • sudo — выполнить команду от имени администратора
  • apt update — обновить список доступных пакетов
  • && — выполнить следующую команду только если предыдущая успешна
  • apt upgrade -y — обновить все установленные пакеты
  • -y — автоматически ответить "да" на все вопросы

Шаг 5: Установка базовых программ

sudo apt install -y curl wget git nano htop tmux

Разбор команды

  • curl — загрузка файлов по URL
  • wget — ещё один загрузчик файлов
  • git — система контроля версий
  • nano — простой текстовый редактор
  • htop — красивый диспетчер задач
  • tmux — менеджер терминалов (позволяет работать с несколькими окнами)
