1 Основные команды навигации

Изучить базовые команды для перемещения по файловой системе и работы с директориями.

  • pwd — показать текущую директорию
  • ls — вывести содержимое каталога (ls -la — с правами и скрытыми файлами)
  • cd — переход в директорию (cd /var/log, cd .., cd ~)
  • mkdir — создать директорию (mkdir -p a/b/c)
  • rmdir — удалить пустую директорию
$ pwd
/home/user
$ mkdir -p practice/test
$ cd practice/test
$ ls -la
$ cd ..
$ rmdir practice/test

2 Работа с файлами

Освоить создание, копирование, переименование и удаление файлов.

  • touch file.txt — создать пустой файл
  • cp file1 file2 — скопировать файл (cp -r dir1 dir2 для каталогов)
  • mv file1 file2 — переименовать или переместить
  • rm file — удалить файл (rm -rf dir — рекурсивно и без подтверждения)
$ touch notes.txt
$ cp notes.txt notes.bak
$ mv notes.bak backup_notes.txt
$ rm notes.txt
Совет: будьте осторожны с rm -rf — команда удаляет безвозвратно и без подтверждения.

3 Управление правами доступа

Научиться изменять права на файлы и владельцев.

  • chmod — изменить права (chmod 755 script.sh, chmod +x script.sh)
  • chown — изменить владельца (chown user:group file)
$ chmod 644 document.txt
$ chmod +x deploy.sh
$ sudo chown www-data:www-data /var/www/html -R
Расшифровка: r=4, w=2, x=1. 755 = rwxr-xr-x, 644 = rw-r--r--.

4 Работа с текстовыми редакторами

Попробовать редактировать файлы в консоли разными редакторами.

  • nano file.txt — простой редактор, горячие клавиши внизу экрана
  • vim file.txt — мощный модальный редактор (:w — сохранить, :q — выйти, :wq — сохранить и выйти)
  • emacs file.txt — расширяемый редактор
$ nano hello.txt
# Ctrl+O — сохранить, Ctrl+X — выйти

$ vim hello.txt
# i — вставка, Esc — нормальный режим, :wq — сохранить и выйти

5 Поиск файлов и текста

Использовать find и grep для поиска файлов и фрагментов текста.

  • find /path -name "*.log" — поиск по имени
  • find . -type f -size +10M — файлы больше 10 МБ
  • grep "error" file.log — поиск строки в файле
  • grep -r "TODO" . — рекурсивный поиск
$ find /var/log -name "*.log" -mtime -7
$ grep -i "failed" /var/log/syslog
$ grep -rn "password" ./config/

6 Работа с процессами

Запускать фоновые процессы и отслеживать их состояние.

  • command & — запустить в фоне
  • jobs — список фоновых задач
  • ps aux — все процессы
  • top / htop — интерактивный мониторинг
  • kill PID, kill -9 PID — завершение процесса
$ sleep 300 &
[1] 2451
$ ps aux | grep sleep
$ kill 2451

7 Настройка сетевых параметров

Изучить сетевые утилиты для диагностики и загрузки данных.

  • ifconfig / ip addr — информация о сетевых интерфейсах
  • ping host — проверка доступности узла
  • curl — отправка HTTP-запросов
  • wget — скачивание файлов из сети
$ ip addr show
$ ping -c 4 8.8.8.8
$ curl https://api.github.com
$ wget https://example.com/file.tar.gz

8 Управление пакетами

Устанавливать, обновлять и удалять программное обеспечение.

  • Debian/Ubuntu: apt update, apt install pkg, apt remove pkg
  • RHEL/CentOS: yum install pkg, yum remove pkg (или dnf)
$ sudo apt update
$ sudo apt install htop
$ sudo apt remove htop

# RHEL/CentOS
$ sudo yum install epel-release
$ sudo yum install htop

9 Работа с архивами

Упаковывать и распаковывать файлы и каталоги.

  • tar — архиватор (-c создать, -x распаковать, -z gzip, -f файл)
  • gzip / gunzip — сжатие одиночных файлов
  • unzip — распаковка zip-архивов
$ tar -czf backup.tar.gz /home/user/data
$ tar -xzf backup.tar.gz -C /tmp
$ gzip large.log
$ unzip archive.zip -d ./extracted

10 Создание и использование скриптов

Написать простой bash-скрипт для автоматизации задач.

#!/bin/bash
# backup.sh — простой скрипт резервного копирования

SRC="/home/user/data"
DST="/backup/$(date +%Y-%m-%d)"
mkdir -p "$DST"
cp -r "$SRC"/* "$DST"
echo "Backup completed: $DST"
$ chmod +x backup.sh
$ ./backup.sh

11 Работа с пользовательскими аккаунтами

Создать нового пользователя, настроить права и проверить переключение.

  • useradd / adduser — создать пользователя
  • passwd — установить пароль
  • usermod — изменить параметры (usermod -aG sudo user)
  • su / sudo — переключение и повышение прав
$ sudo adduser alice
$ sudo usermod -aG sudo alice
$ su - alice
$ sudo whoami
root

12 Системный мониторинг

Следить за ресурсами системы в реальном времени.

  • free -h — использование памяти
  • df -h — свободное место на дисках
  • du -sh /path — размер каталога
  • iotop / iostat — активность дисков
$ free -h
$ df -h
$ du -sh /var/log/*
$ sudo iotop

13 Настройка cron-задач

Планировать регулярное выполнение команд.

  • crontab -e — редактировать задачи текущего пользователя
  • crontab -l — список активных задач
  • Формат: минута час день месяц день_недели команда
# каждый день в 3:30 — запуск бэкапа
30 3 * * * /home/user/backup.sh >> /var/log/backup.log 2>&1

# каждые 5 минут — проверка статуса
*/5 * * * * /usr/bin/check_status.sh

14 Символические ссылки

Создавать и использовать ссылки на файлы и каталоги.

  • ln -s target link — создать символическую ссылку
  • ln target link — жёсткая ссылка
  • ls -l — покажет ссылку символом ->
$ ln -s /usr/local/bin/python3.11 /usr/bin/python
$ ls -l /usr/bin/python
lrwxrwxrwx ... /usr/bin/python -> /usr/local/bin/python3.11

15 Базовые операции с Git

Настроить Git, работать с ветками и отправлять изменения в удалённый репозиторий.

# настройка
$ git config --global user.name "Иван Иванов"
$ git config --global user.email "ivan@example.com"

# инициализация и первый коммит
$ git init
$ git add .
$ git commit -m "Initial commit"

# работа с ветками
$ git branch feature/login
$ git checkout feature/login
# ... правки ...
$ git add .
$ git commit -m "Add login form"

# слияние и отправка
$ git checkout main
$ git merge feature/login
$ git remote add origin git@github.com:user/repo.git
$ git push -u origin main
Совет: перед push всегда делайте git pull --rebase, чтобы избежать конфликтов.
