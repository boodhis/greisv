# Цифровая Крепость

Образовательный сайт о Linux и homelab-самостоятельности.

## Концепция

Показать что Linux — это просто, надёжно и круто. Через реальный пример домашней лаборатории.

### Целевая аудитория

- Новички, которые хотят попробовать Linux
- Те, кто пробовал и "всё сломалось"
- Энтузиасты, которые хотят собрать свою "цифровую крепость"

## Технологии

- **Astro** — статический генератор сайтов
- **Starlight** — тема для документации
- **GitHub Pages** — бесплатный хостинг
- **Obsidian** — источник контента

## Структура сайта

```
/
├── index.mdx              — Главная (манифест)
├── getting-started/       — С чего начать
├── homelab/               — Концепция "крепости"
├── services/              — Сервисы (Docker, Samba, etc.)
├── guides/                — Гайды и инструкции
└── resources/             — Полезные ссылки
```

## Локальная разработка

### Установка зависимостей

```bash
npm install
```

### Запуск dev-сервера

```bash
npm run dev -- --host 0.0.0.0 --port 4321
```

Открой в браузере: `http://192.168.0.244:4321`

### Сборка

```bash
npm run build
```

## Синхронизация контента

Контент берётся из Obsidian vault (`/home/iva/obsid/серверные/`).

### Запуск синхронизации

```bash
./sync-site.sh
```

Скрипт копирует заметки из Obsidian в структуру сайта.
