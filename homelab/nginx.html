Nginx

Reverse proxy, TLS, базовая настройка в homelab.

Nginx — reverse-proxy и веб-сервер. Принимает трафик на 80/443, терминирует TLS, раздаёт статику и проксирует приложения. Здесь — то, что чаще всего нужно после базовой установки.

TLS через certbot

sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d app.local -d www.app.local
sudo systemctl status certbot.timer

Certbot сам правит конфиг, добавляет редирект и настраивает автообновление. Проверка:

sudo certbot renew --dry-run

Redirect http → https

server {
    listen 80;
    server_name app.local;
    return 301 https://$host$request_uri;
}

Upstream

Проксирование на приложение, в том числе на несколько инстансов:

upstream app_backend {
    server 127.0.0.1:8000;
    server 127.0.0.1:8001;
    keepalive 16;
}

server {
    listen 443 ssl http2;
    server_name app.local;

    ssl_certificate /etc/letsencrypt/live/app.local/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/app.local/privkey.pem;

    location / {
        proxy_pass http://app_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

gzip

gzip on;
gzip_comp_level 5;
gzip_min_length 1024;
gzip_types text/plain text/css application/json application/javascript application/xml image/svg+xml;
gzip_vary on;

Заголовки безопасности

add_header X-Content-Type-Options "nosniff" always;
add_header X-Frame-Options "SAMEORIGIN" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
add_header Content-Security-Policy "default-src 'self'" always;

Проверка и reload

sudo nginx -t
sudo systemctl reload nginx

HSTS включай последним

Строгий HSTS заставляет браузер ходить только по https. Если сертификат сломается, откатиться будет тяжело. Сначала убедись, что автопродление работает.
