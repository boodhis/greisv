Что такое Homelab?

Homelab — это домашняя лаборатория для изучения технологий. Это как научная лаборатория, но для компьютерных наук: сервер из старого ноутбука, Docker-сервисы, своё хранилище и бэкапы. Всё — бесплатно и под своим контролем.

Концепция "Цифровой Крепости"

Наш homelab — это не просто набор компьютеров. Это система:

┌─────────────────────────────────────────────────┐
│                 Цифровая Крепость               │
├─────────────────────────────────────────────────┤
│  🖥️ Сервер         │  💾 Диски                  │
│  ├─ Ubuntu Server   │  ├─ Системный (240G)      │
│  ├─ Docker          │  ├─ Хранилище (1TB)       │
│  └─ Сервисы         │  ├─ Архив (2TB)           │
│                     │  └─ Флешка (30G)           │
├─────────────────────────────────────────────────┤
│  🌐 Сеть            │  🔒 Безопасность          │
│  ├─ WiFi            │  ├─ Firewall (UFW)        │
│  ├─ SSH по ключам   │  ├─ Бэкапы (3-2-1)        │
│  └─ VPN: план       │  └─ Мониторинг (smartd)   │
└─────────────────────────────────────────────────┘

Уточнение по дискам: помимо встроенного системного накопителя (240G), рабочие данные разложены по внешним накопителям, подключённым к ноутбуку по USB — для старого ноутбука это нормальная схема. Суммарно это четыре накопителя (~3,3 ТБ), а упомянутая в старых текстах «общая ёмкость 4 ТБ» — это расчёт по номиналу дисков округлённо.

Принципы

  1. Простота — используем только проверенные решения
  2. Надёжность — всё должно работать после перезагрузки
  3. Документация — каждое действие описано
  4. Открытый код — конфиги и инструкции опубликованы, можно копировать и адаптировать под себя

Безопасность и бэкапы

Homelab — это не только «как классно». Это ещё и ответственность за данные. Минимальный набор:

  • SSH только по ключам — пароль для входа отключить
  • Firewall — ufw, открыты только нужные порты в локальной сети
  • Без проброса портов наружу — внешний доступ через VPN (WireGuard/Tailscale), а не открытые в интернет порты
  • Обновления — регулярно, или автоматически через unattended-upgrades
  • Бэкапы 3-2-1 — три копии, два носителя, одна — вне дома
  • Fail2ban — если открыт доступ извне, блокирует перебор паролей

Предупреждение

Старый ноутбук работает 24/7 — следи за температурой, пылью и состоянием батареи. Если батарея вздулась — убери её и работай от сети.

Как начать?

  1. Выбери железо — подойдёт даже старый ноутбук или мини-ПК
  2. Установи Ubuntu Server — инструкция в разделе «С чего начать»
  3. Настрой SSH и UFW — гайд по SSH
  4. Поставь Docker — как запустить свой первый сервис
  5. Настрой бэкапы — гайд по резервному копированию
  6. Документируй — записывай, что делаешь, чтобы повторить на новом железе

Дальше по плану

  • VPN — WireGuard или Tailscale для доступа снаружи дома
  • Мониторинг — Uptime Kuma / Netdata для наглядности
  • Умный дом — связка MQTT + ESPHome уже работает, расширяем
