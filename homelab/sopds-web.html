Проект «Библиотека»

Пересборка веб-морды SOPDS «на современные рельсы»: что это, на чём основано, как работает и что готово.

Что это

Задача-ветка (от юзера): «пересобрать всю петрушку — веб-морда SOPDS, поиск, всё что к ней прикручено». Вместо старого интерфейса на чужих Django/Foundation-шаблонах — чистый современный тёмный интерфейс с быстрым поиском по всей библиотеке. База и каталог книг не трогаются. Развёрнута в Docker на хомлабе: http://192.168.0.244:8091 (здоровье: /healthz → v0.4.0 · 333 462 книги). Старый прод :8081 отключён (20.09.2026) и убран в архив; работает новая морда на :8091.

Как это работает

Архитектура

Браузер (карточки, поиск, читалка)
   │  :8091  uvicorn ← FastAPI (app.py)
   ├─→ PostgreSQL каталога   → поиск, карточки, жанры (<0.1 с)
   ├─→ /mnt/devlib/*.zip     → чтение fb2, скачивание, /cover/{id}
   │
   └─→ Озвучка: /voice/{id} → audiobook.php?add=1 (сервер 192.168.0.244)
        └→ очередь → worker → edge/piper/gtts → m4b с главами

Инженерные решения (портфолио)

ЗадачаРешение
Поиск по 400k книг < 0.1 сPostgreSQL 14 + pg_trgm GIN; хит-путь: UNION под-запросов по id (название+автор+серия) → DISTINCT id → один JOIN на страницу. Без этого LEFT JOIN + GROUP BY = 2.5 с
Фильтр «только русские»Накладывается на стыках, а не в БД — данные продакшена чисты
Читалка FB2Конвертер fb2 → HTML через ElementTree, без хранения XSLT/кэшей
Скачивание .zipFileResponse (стриминг + Range) — не грузит 1.7-ГБ архив в ОЗУ
Библиотека книгSSHFS (176 zip ≈ 304 ГБ на homelab) — не нужны локальные 300 ГБ; извлекается один FB2 по запросу
Озвучка307-редирект на фабрику аудио (edge-tts/piper) с параметрами книги
Автостартuser systemd unit, restart=on-failure
Почему стек FastAPI

FastAPI + HTMX + Jinja2 — один язык на весь стек (без Node); HTMX даёт инфініти-скролл и живой поиск без SPA-фреймворка. PostgreSQL каталога — read-only, данные не трогаются.

Шаги (как собирали)

  1. Разведка — вытащили с сервера шаблоны, views, логику фильтра «русские» и кнопку озвучки; локальная копия ~/sopds-dev.
  2. Выбор стека — FastAPI + HTMX (договорились с юзером).
  3. Веб-морда — поиск <0.1 с по каталогу, тёмная тема, карточки, пагинация, инфинити.
  4. Главная — случайные подборки разных направлений + история «читал/скачивал/озвучивал».
  5. Чтение и библиотека — читалка FB2, избранное, прогресс чтения (всё локально в браузере, без авторизации).
  6. Озвучка — кнопка «🎧 Озвучить» e2e: фикс бага «всё пропущено как дубликат», движки edge/piper/gtts, 7 голосов.
  7. Обложки — превью в карточках из fb2-архивов с кэшем на диск.
  8. Сделано (20.09.2026) — старая морда :8081 отключена и заархивирована, живёт новая на :8091. Осталось — store-функционал (добавление/правка книг) и проверка E2E.
