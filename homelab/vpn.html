VPN

WireGuard, Tailscale — настройка безопасного доступа.

WireGuard — современный VPN: быстрый, простой конфиг, встроен в ядро Linux. Нужен, чтобы попадать в домашнюю сеть извне и не выставлять сервисы в интернет. Здесь — установка, ключи, конфиги, systemd, ufw.

Установка

sudo apt install wireguard

Генерация ключей

umask 077
wg genkey | tee server.key | wg pubkey > server.pub
wg genkey | tee client1.key | wg pubkey > client1.pub

Приватные ключи — только на своей машине, права 600. Публичные можно передавать.

Конфиг сервера

# /etc/wireguard/wg0.conf
[Interface]
Address = 10.10.0.1/24
ListenPort = 51820
PrivateKey = <server.key>

[Peer]
PublicKey = <client1.pub>
AllowedIPs = 10.10.0.2/32

Конфиг клиента

[Interface]
Address = 10.10.0.2/32
PrivateKey = <client1.key>
DNS = 10.10.0.1

[Peer]
PublicKey = <server.pub>
Endpoint = vpn.example.local:51820
AllowedIPs = 10.10.0.0/24, 192.168.0.0/24
PersistentKeepalive = 25

AllowedIPs решает, какой трафик идёт в туннель. Только внутренние сети — VPN для доступа. 0.0.0.0/0 — весь трафик через сервер.

Запуск через systemd

sudo systemctl enable --now wg-quick@wg0
sudo systemctl status wg-quick@wg0
sudo wg show

ufw

sudo ufw allow 51820/udp
sudo ufw allow in on wg0
sudo ufw enable

Форвардинг для выхода в интернет:

# /etc/sysctl.d/99-wg.conf
net.ipv4.ip_forward=1

sudo sysctl --system
sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE

Правило выбора

Есть статический IP и желание контролировать — WireGuard. Нет IP, несколько устройств за NAT, нужен zero-config — Tailscale.
