Мониторинг

Быстрая проверка состояния сервера: CPU, ОЗУ, диски, сеть, логи.

Системные ресурсы

htop
free -h
uptime

Диски

df -hT
lsblk
du -sh /* 2>/dev/null | sort -h

Сеть

ip addr show
ss -tulnp
ping -c 4 1.1.1.1

Логи

journalctl -p err -b --since "1h ago"
journalctl -u <service>.service -n 20

Контейнеры

docker ps
docker stats --no-stream
