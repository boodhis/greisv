Сеть и безопасность

Базовая настройка сети

Проверка текущих настроек

ip a

Разбор команды

Показывает все сетевые интерфейсы и их IP-адреса. Ищи строку с inet — это твой IP.

Статический IP (рекомендуется)

Для сервера нужен статический IP, чтобы он не менялся после перезагрузки.

sudo nano /etc/netplan/00-installer-config.yaml

Пример конфигурации:

network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: false
      addresses:
        - 192.168.1.100/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 8.8.4.4

Примени изменения:

sudo netplan apply

Разбор команды

  • dhcp4: false — отключить автоматическое получение IP
  • addresses — статический IP-адрес
  • routes — шлюз (обычно IP роутера)
  • nameservers — DNS-серверы (Google: 8.8.8.8)

Firewall (UFW)

Ubuntu поставляется с простым файрволом UFW.

Включение файрвола

sudo ufw enable

Разрешение SSH (обязательно!)

sudo ufw allow OpenSSH

Проверка статуса

sudo ufw status

Разбор команды

  • ufw enable — включить файрвол
  • allow OpenSSH — разрешить входящие SSH-подключения
  • status — показать текущие правила

Доступ к сервисам

Если нужно открыть порты для сервисов:

# HTTP (веб-сервер)
sudo ufw allow 80/tcp

# HTTPS (зашифрованный веб)
sudo ufw allow 443/tcp

# Docker (осторожно!)
sudo ufw allow 2375/tcp

Безопасность Docker

Не открывай порт 2375 без аутентификации! Это даст полный доступ к Docker.

SSH-безопасность

Ключи вместо паролей

Генерация ключа на клиенте:

ssh-keygen -t ed25519 -C "your_email@example.com"

Копирование ключа на сервер:

ssh-copy-id iva@192.168.1.100

Отключение парольной авторизации:

sudo nano /etc/ssh/sshd_config

Добавь или измени:

PasswordAuthentication no
PubkeyAuthentication yes

Перезапусти SSH:

sudo systemctl restart ssh

Разбор команды

  • ssh-keygen — генерация SSH-ключа
  • ed25519 — современный и безопасный алгоритм
  • ssh-copy-id — копирование публичного ключа на сервер

Мониторинг сети

Проверка открытых портов

sudo ss -tulpn

Разбор команды

  • ss — утилита для просмотра сетевых соединений
  • t — TCP
  • u — UDP
  • l — слушающие порты
  • p — показывать процессы
  • n — числовые адреса (не DNS)

Проверка подключения

ping -c 4 google.com

Разбор команды

Отправляет 4 ICMP-пакета к google.com. Если есть ответ — интернет работает.
