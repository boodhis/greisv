# Инструкция по вёрстке — Цифровая Крепость

Сайт — это **обычные HTML-файлы** в этой папке (`/home/iva/greisv`), никаких сборщиков и фреймворков.
Правишь файл → сохраняешь → `git push` → GitHub Pages сам обновляет сайт.

> Синхронизация из Obsidian (автоген `gen_vault.py`) **отключена**. Все страницы правятся здесь, прямо в HTML.

## Как устроен сайт

```
greisv/
├── index.html            ← главная (шапка + список 5 разделов)
├── manifest.html         ← манифест
├── style.css             ← единственный источник стилей
├── sw.js                 ← офлайн-кеш + список страниц
├── sitemap.xml           ← карта сайта для поисковиков
├── getting-started/      ← Крепость: ubuntu, первые шаги, флешка
├── homelab/              ← Homelab: железо, сеть, сервисы, практические гайды
├── electric/             ← Электрика: безопасность, щиты, монтаж, инструменты, нормативы
├── study/                ← Обучение: курсы, шпаргалки, разборы
├── articles/             ← Заметки: эссе, книги, досуг
└── gen/                  ← генераторы (icons)
```

Разделов пять (раньше было восемь; `guides/`, `services/`, `hobbies/`
разобраны — их страницы разложены по `homelab/` и `study/`):

| Раздел | Папка | Что внутри |
|---|---|---|
| Крепость | `getting-started/` | с чего начать, манифест (корень) |
| Homelab | `homelab/` | железо, сеть, 9 сервисов, 8 серверных гайдов |
| Электрика | `electric/` | 7 страниц: безопасность, щиты, монтаж, компоненты, умный дом, инструменты, нормативы |
| Обучение | `study/` | курсы (python, devops, linux-app-dev, веб), шпаргалки, 6 разборов |
| Заметки | `articles/` | эссе, «Книги, которые нас сделали», досуг |

- **Папка = раздел**, файл `x.html` = страница `https://boodhis.github.io/greisv/x.html`.
- **Главная и манифест** — в корне, остальные — в подпапках.
- Внутри каждой папки может быть свой `index.html` — страница раздела.

## Типовая страница статьи

```html
<!DOCTYPE html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Название — Цифровая Крепость</title>
<meta name="description" content="Описание для поиска и OG">
<link rel="icon" type="image/svg+xml" href="../favicon.svg">  <!-- ../ в подпапках, в корне просто favicon.svg -->
<link rel="stylesheet" href="../style.css">                     <!-- если пользуешься общими стилями -->
</head>
<body>
<div class="layout">
<aside>   <!-- боковое меню не всегда: в новых страницах вместо него верхняя рамка .fnav (см. ниже) -->
</aside>
<main>
<h1>Название статьи</h1>
<p class="desc">Короткое описание под заголовком</p>

<p>Текст абзаца.</p>
<h2>Подзаголовок</h2>
<ul>
<li>пункт 1</li>
<li>пункт 2</li>
</ul>
<pre><code>sudo systemctl status nginx</code></pre>
</main>
</div>
</body>
</html>
```

### Общие стили (`style.css`)
Если страница подключает `style.css`, доступны:
- `class="callout"` → блок-справка. Варианты: `callout-note`, `callout-warning`.
- `class="grid"` + `class="card"` → сетка карточек (см. главную).
- `h1 h2 h3 p ul ol pre code table` — уже оформлены.
- `class="desc"` — подзаголовок-описание.

### Верхняя рамка навигации (fnav) — у современных страниц
Вместо бокового меню — рамка вверху:


## Цвета и стиль
Тема «тёплая бумага»: матовая светлая поверхность, книжная типографика.
Цвет остался только там, где работает как знак, — в точках разделов.

| Что | Значение |
|---|---|
| фон (бумага) | `#f4f1e8` |
| панель | `#fbf9f3` |
| бордеры | `#d8d3c2` |
| текст | `#1c1c1a` |
| приглушённый | `#6b6659` |
| акцент (тёмный хвойный) | `#0a5c52` |
| охра / второй цвет | `#7d611b` |
| предупреждение | `#a13d2a` |
| совет | `#3d5c2c` |

Шрифт тела — `Georgia`, `Iowan Old Style`, `Charter`: 17px, `line-height: 1.65`,
`main` ограничен 68ch. Код и ASCII — `JetBrains Mono`, `SF Mono`, Consolas.

Не возвращать: `text-shadow`, `body::after` (CRT-развёртка), `backdrop-filter`,
`linear-gradient`, скругления вида `999px`. Это проверяется тестами
`test_no_text_shadow` и `test_no_neon_colors`.

## После правки

1. Проверь глазами в браузере.
2. Прогони тесты, чтобы ничего не сломалось:
   ```bash
   python3 tests/test_site.py
   ```
3. Если добавил **новую** страницу — впиши её в три места:
   - `sw.js` → список `ASSETS` (и подними `var CACHE = "fortress-v14";` → v15 => клиент обновится);
   - `sitemap.xml` → добавь `<url>`;
   - если есть блок «Связанные страницы» на странице раздела — добавь ссылку.
   После этого тесты `test_sw_precache_covers_all_pages` и `test_sitemap_covers_all_pages` обязаны пройти.
4. Коммит и пуш (сайт обновится за ~1 минуту):
   ```bash
   git add -A && git commit -m "Название" && git push
   ```

> Примечание: `electric/` (электрика) имеет свой генератор (`gen/gen_electric.py`) — его не трогают руками, кроме контента.

## Частые приёмы

- **Ссылка на другую страницу**: `<a href="../homelab/navidrome.html">Navidrome</a>` (относительно папки текущей страницы).
- **Внешняя ссылка**: `<a href="https://...">…</a>`.
- **Карточка в сетке**:
  ```html
  <div class="grid">
  <div class="card"><h4>Заголовок</h4><p>Текст.</p></div>
  </div>
  ```
- **Спойлер/вкладка**: обычный `<details><summary>…</summary>…</details>`.
- **Виджет «Слово дня»** на страницах (без кнопок — простое «слово дня»; на главной — мини-тренажёр с кнопками):
  ```html
  <div id="wordday" style="display:none"></div>
  <script src="study/data/wordday.js"></script>
  <script src="study/data/srs.js"></script>   <!-- только если есть кнопки -->
  <script src="study/data/widget.js"></script>
  ```
  Чтобы включить режим мини-тренажёра, добавь в `#wordday` блок
  `<div class="wd-actions">` с кнопками `.wd-reveal` (primary), `.wd-forgot` (danger), `.wd-ok` (primary) — стили есть в `index.html`.

Если сомневаешься — открой соседнюю похожую страницу в этом репозитории и сделай по её шаблону.
